Bit Manipulation

XOR, shifts and masks: solve counting problems with the bits themselves.

Prerequisites: 1-D Dynamic Programming

What it is

Every integer is stored as a row of bits, digits that are 0 or 1. Reading from the right, the bit at position i is worth 2**i, so 1011 is 8 + 0 + 2 + 1 = 11. Picture a row of light switches: the number is the pattern of which switches are on. A bit that is 1 is called a set bit, and counting the set bits is a popcount.

Bit manipulation means working on those switches directly. One operator touches all of them at once, so a few short expressions replace a loop over positions or an extra hash set. The operators, in Python spelling:

  • a & b is AND: a bit is 1 only if it is 1 in both numbers. Use it to test or keep bits.
  • a | b is OR: a bit is 1 if it is 1 in either number. Use it to switch bits on.
  • a ^ b is XOR (exclusive or): a bit is 1 when the two bits differ. Use it to flip bits and to cancel equal values.
  • ~a is NOT: it flips every bit. In Python, ~a is the same as -a - 1.
  • a << k shifts the bits left by k places and fills with zeros, which multiplies by 2**k.
  • a >> k shifts right by k places and drops the lowest k bits, which floor-divides by 2**k.

Three facts do most of the work in this topic:

  • x & (x - 1) erases the lowest set bit. Subtracting 1 turns the lowest 1 into 0 and every 0 below it into 1, like 1000 - 1 = 0999 in decimal. ANDing with x keeps everything above that spot and zeroes the rest.
  • x & -x keeps only the lowest set bit. Negating flips all bits and adds 1; the carry from that + 1 runs through the trailing zeros and stops at the lowest 1, so that is the one position where x and -x still agree on a 1.
  • XOR cancels pairs. a ^ a = 0 and a ^ 0 = a, and the order does not matter. XOR-ing a whole list therefore leaves exactly the values that appear an odd number of times.

Python differs from C and Java here. Python integers have no fixed width: they grow as needed and never overflow. Negative numbers follow two's complement (the scheme hardware uses: in w bits, -x is stored as the pattern of 2**w - x, so -1 in 8 bits is 11111111), but Python pretends there are infinitely many leading 1s, so -1 >> 1 is still -1. A problem that says "32-bit integer" therefore needs you to simulate the width with a mask, a number whose 1-bits mark the positions you want to keep. x & 0xFFFFFFFF keeps the low 32 bits and turns -1 into 4294967295. Pattern 4 below packages this into small helper functions.

How to recognise it

  • The statement mentions the binary representation, bits, a 32-bit integer, or forbids +, -, * or / and asks you to build arithmetic from bit operations.
  • Every number appears twice except one (or one number is missing from a complete range) and you must use O(1) extra space: XOR cancels the pairs.
  • You must count, test, flip or reverse individual bits, or compare two numbers by the positions where they differ (their XOR).
  • The answer for i can be derived from the answer for i with its last bit removed (i >> 1) or its lowest set bit erased (i & (i - 1)), so a table over 0..n fills in O(n).
  • A handful of yes/no flags (up to about 20 to 30) must be stored compactly or enumerated: a bitmask where bit i says whether item i is chosen.
  • The statement quotes 32-bit limits (-2**31 to 2**31 - 1) and says what to do on overflow. Python never overflows, so you have to enforce the limit yourself.

Counting 1-bits by erasing the lowest one

Each round computes n & (n - 1), which erases the lowest set bit. The number of rounds until n reaches 0 is the number of set bits, however wide the number is.

Patterns and Python templates

Read, set, clear and flip one bit

Use it when: you need to inspect or change one specific bit, or build a mask for a set of positions.

def get_bit(x: int, i: int) -> int:
    return (x >> i) & 1             # slide bit i down to position 0, then keep only that bit

def set_bit(x: int, i: int) -> int:
    return x | (1 << i)             # 1 << i is a mask with only bit i switched on

def clear_bit(x: int, i: int) -> int:
    return x & ~(1 << i)            # ~mask has every bit on except bit i

def toggle_bit(x: int, i: int) -> int:
    return x ^ (1 << i)             # XOR with 1 flips a bit, XOR with 0 leaves it alone

Bit 0 is the rightmost (least significant) bit. Shifts bind looser than + and -, so 1 << i + 1 means 1 << (i + 1): write the parentheses so the next reader does not have to remember.

Erase or isolate the lowest set bit

Use it when: you count set bits, test for a power of two, or peel set bits off one at a time.

def count_set_bits(x: int) -> int:
    count = 0
    while x:
        x &= x - 1                  # erase the lowest 1-bit
        count += 1                  # ... and count it
    return count                    # one round per 1-bit, not one per position

def lowest_set_bit(x: int) -> int:
    return x & -x                   # 0b101100 -> 0b000100

def is_power_of_two(x: int) -> bool:
    return x > 0 and x & (x - 1) == 0   # exactly one 1-bit

The loop runs once per set bit: at most 32 rounds for a 32-bit number, often far fewer. x & -x is the same trick Fenwick (binary indexed) trees use to jump between ranges.

XOR cancels pairs

Use it when: values come in pairs and you want the one that does not, in O(1) extra space.

def find_single(nums: list[int]) -> int:
    """Every value appears twice except one."""
    acc = 0                         # 0 is the identity of XOR: 0 ^ x == x
    for x in nums:
        acc ^= x                    # a value seen twice flips the same bits twice
    return acc

def find_missing(nums: list[int]) -> int:
    """nums holds the numbers 0..n with exactly one of them removed."""
    acc = len(nums)                 # n is never an index, so start with it
    for i, x in enumerate(nums):
        acc ^= i ^ x                # index i and value i cancel when both are present
    return acc

XOR cancels pairs. If a value can appear three times, a ^ a ^ a is a, not 0, and the trick no longer works (Single Number II needs per-bit counting modulo 3).

Pretend Python integers have 32 bits

Use it when: the problem says 32-bit, talks about overflow, or has a loop that only ends when a carry falls off the left edge.

MASK = 0xFFFFFFFF                   # 32 one-bits: keeps only the low 32 bits
INT_MAX = 0x7FFFFFFF                # 2**31 - 1, the largest signed 32-bit value

def to_unsigned(x: int) -> int:
    return x & MASK                 # -1 -> 4294967295, 2**32 -> 0

def to_signed(x: int) -> int:
    x &= MASK                       # first force a 32-bit pattern
    return x if x <= INT_MAX else ~(x ^ MASK)   # bit 31 set means negative

def flip_32(x: int) -> int:
    return x ^ MASK                 # NOT within 32 bits; plain ~x would give a negative number

For a pattern with bit 31 set, ~(x ^ MASK) equals x - 2**32 and uses no subtraction (Sum of Two Integers forbids -). Mask after every operation that can grow past 32 bits, such as <<.

Build or read a number one bit at a time

Use it when: you reverse or rotate bits, assemble a number from a stream of bits, or fill a table where dp[i] depends on i with its last bit removed.

def reverse_32(n: int) -> int:
    result = 0
    for _ in range(32):                      # exactly 32 rounds: leading zeros count too
        result = (result << 1) | (n & 1)     # push n's lowest bit onto the right of result
        n >>= 1                              # drop that bit from n
    return result

def popcount_table(n: int) -> list[int]:
    dp = [0] * (n + 1)
    for i in range(1, n + 1):
        dp[i] = dp[i >> 1] + (i & 1)         # i is (i >> 1) followed by one more bit
    return dp

Pushing a bit on the right is (x << 1) | bit; popping the lowest bit is x & 1 followed by x >>= 1. The same idea enumerates subsets: for mask in range(1 << n) visits all 2**n subsets of n items, and bit i of mask says whether item i is in.

Complexity cheat-sheet

OperationCostNote
AND, OR, XOR, NOT and shifts on a 32-bit valueO(1)one machine instruction in C, a cheap small-integer operation in Python
Test, set, clear or flip one bitO(1)one shift and one mask
Erase the lowest set bit with x & (x - 1)O(1)isolate it instead with x & -x
Count set bits by checking every positionO(w)w is the width, 32 in these problems
Count set bits by erasing the lowest one each roundO(k)k is the number of set bits, at most w
XOR of n numbersO(n)one pass, O(1) extra space
x.bit_count() and x.bit_length()O(w / 30)built-ins; CPython stores integers in 30-bit chunks
format(x, "032b")O(w)builds a string, so avoid it inside hot loops

For the fixed-width problems in this topic w is 32, so every loop is a constant number of rounds. Python integers can be arbitrarily wide, and an operation on a b-bit number costs about O(b / 30), which only matters for huge values.

Common mistakes

  • Python never overflows or wraps. 1 << 31 is 2147483648, not a negative number, and ~x is -x - 1, not "the 32 bits flipped". Anything that should behave like a 32-bit integer needs & 0xFFFFFFFF (and the sign conversion in Pattern 4).
  • Loops over a negative number may never end. while n: n >>= 1 is an infinite loop for n < 0, because >> keeps copying the sign bit (-1 >> 1 is -1). Mask to 32 bits first, or loop a fixed number of times.
  • Operator precedence. + and - bind tighter than shifts, and shifts bind tighter than &. So a & b << 1 is a & (b << 1), 1 << n - 1 is 1 << (n - 1), and dp[i >> 1] + i & 1 is (dp[i >> 1] + i) & 1. Python also differs from C here: comparisons bind looser than &, so x & 1 == 0 already means (x & 1) == 0. Parenthesise every bit expression anyway.
  • XOR cancels pairs, not arbitrary repeats. A value that appears three times leaves one copy behind. Before using the trick, check exactly how many times each value may appear.
  • bin() hides the width. bin(5) is '0b101' with no leading zeros, and bin(-5) is '-0b101', not two's complement. When the width matters, use format(x & 0xFFFFFFFF, "032b").

Python tips

  • bin(x), format(x, "08b") and f"{x:08b}" show bits as text; int("1011", 2) parses them back; 0b1011, 0xFF and 0o17 are literals.
  • x.bit_length() is the number of bits needed ((40).bit_length() is 6) and x.bit_count() is the popcount (Python 3.10 and later). bin(x).count("1") does the same on older versions.
  • ^=, |=, &=, <<= and >>= update in place. functools.reduce(operator.xor, nums) XORs a whole list in one expression.
  • divmod(x, 10) returns the quotient and remainder together, which is handy when you peel digits off the same way you peel bits.
