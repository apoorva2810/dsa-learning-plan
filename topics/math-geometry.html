Math & Geometry

Matrix tricks, digit handling, fast power and a bit of geometry.

Prerequisites: Graphs, 2-D Dynamic Programming

What it is

This topic is a collection of small, concrete tricks rather than one big idea. None of them needs advanced maths: each one replaces a slow or messy first attempt with a short loop.

  • Matrix index tricks. A matrix is a list of rows, and most of these problems ask where each cell goes. A quarter turn of a square picture is two easy moves: transpose (swap rows and columns, so cell [r][c] trades places with [c][r]), then reverse every row. A spiral is four straight walks around a rectangle that shrinks by one on each side after every lap. Doing it in place means changing the list you were given instead of building a second matrix.
  • Digit arithmetic. Numbers arrive as lists or strings of digits, as on paper. Work from the rightmost digit, keep a carry (the 1 you write above the next column when a column adds up to 10 or more), and let divmod(total, 10) hand you the carry and the digit in one call.
  • Fast power. x to the power n does not need n multiplications. Square the base and halve the exponent in each round, and two billion steps become about 31.
  • Processes that might loop. "Repeat this rule until you reach 1" either ends or revisits a value forever. A set of the values already seen, or a slow and a fast pointer, tells you which.
  • Limits the statement imposes. Python integers never overflow, but a problem can say "pretend integers are 32-bit". Then you must check the range.

Long multiplication is the everyday picture: line up the digits, multiply one pair at a time, carry, add the rows. Much of this topic is that routine written as a loop. In Python the tools are divmod, slicing with a negative step (row[::-1]), zip(*matrix) for transposing, the built-in pow(x, n, mod), sets, and Counter for counting points.

How to recognise it

  • A matrix must be rotated, flipped, spiralled or have rows and columns changed in place (O(1) extra space): think index arithmetic, not a second matrix.
  • Numbers come as strings or digit lists, often with a rule like do not convert the whole string to an integer: do school arithmetic from the last digit, with a carry.
  • A power with an exponent up to 2³¹, or a result "modulo 10⁹ + 7": halve the exponent each step (fast exponentiation).
  • "Repeat the rule until it reaches 1", or any process that applies the same step again and again: it either ends or revisits a value. Catch the repeat with a set, or with a slow and a fast pointer.
  • The statement says to assume 32-bit integers, or to return 0 on overflow: Python will not overflow for you, so test the range yourself.
  • Points on a plane and squares or rectangles with sides parallel to the axes: two opposite corners fix the other two, so look them up in a hash map of points.

Patterns and Python templates

Matrix index tricks: transpose + reverse, and four shrinking edges

Use it when: you rotate, flip or walk a 2-D grid in a fixed order, usually without allocating a second matrix.

def rotate_clockwise(matrix: list[list[int]]) -> None:
    """Quarter turn of an n x n matrix, in place."""
    n = len(matrix)
    for r in range(n):                        # 1) transpose: swap [r][c] with [c][r]
        for c in range(r + 1, n):             #    start at r + 1 so each pair swaps once
            matrix[r][c], matrix[c][r] = matrix[c][r], matrix[r][c]
    for row in matrix:                        # 2) mirror every row left <-> right
        row.reverse()


def spiral_order(matrix: list[list[int]]) -> list[int]:
    top, bottom = 0, len(matrix) - 1
    left, right = 0, len(matrix[0]) - 1
    order = []
    while top <= bottom and left <= right:    # something is still inside the four edges
        for c in range(left, right + 1):      # top edge, going right
            order.append(matrix[top][c])
        top += 1
        for r in range(top, bottom + 1):      # right edge, going down
            order.append(matrix[r][right])
        right -= 1
        if top <= bottom:                     # bottom edge, going left (a lone row is already used up)
            for c in range(right, left - 1, -1):
                order.append(matrix[bottom][c])
            bottom -= 1
        if left <= right:                     # left edge, going up (a lone column is already used up)
            for r in range(bottom, top - 1, -1):
                order.append(matrix[r][left])
            left += 1
    return order

Transpose then reverse every row is a clockwise turn. For counter-clockwise, transpose then reverse the order of the rows (matrix.reverse()). In the spiral, each edge is shrunk right after it is walked; the two if guards stop a leftover single row or column from being walked twice.

Digit loops with divmod (and the carry)

Use it when: you need the digits of an integer, or you add or multiply numbers stored as digit lists or strings.

def digits_of(n: int) -> list[int]:
    """Digits of a non-negative integer, least significant first: 123 -> [3, 2, 1]."""
    digits = []
    while n:
        n, digit = divmod(n, 10)              # n // 10 and n % 10 in one call
        digits.append(digit)
    return digits or [0]                      # the number 0 has one digit


def add_one(digits: list[int]) -> list[int]:
    """Add 1 to a number stored most significant digit first: [1, 9] -> [2, 0]."""
    carry = 1
    for i in range(len(digits) - 1, -1, -1):  # right to left, like on paper
        carry, digits[i] = divmod(digits[i] + carry, 10)
        if carry == 0:                        # nothing to carry: the digits further left cannot change
            return digits
    return [1] + digits                       # a carry fell off the left end: 999 + 1 = 1000

Work from the right because the carry moves left. To add two numbers, keep one index per number and add the carry as a third term. divmod(total, 10) always returns (carry, digit) when total is a column sum.

Fast exponentiation: square the base, halve the exponent

Use it when: a power, or the same operation repeated n times, with n up to billions (also the modular version).

def power(x: float, n: int) -> float:
    if n < 0:                                 # x^(-n) is (1/x)^n
        x, n = 1 / x, -n
    result = 1.0
    while n:
        if n & 1:                             # this bit of n is set: the current x belongs in the answer
            result *= x
        x *= x                                # x, x^2, x^4, x^8, ...
        n >>= 1                               # move on to the next bit
    return result


def power_mod(x: int, n: int, mod: int) -> int:
    result = 1
    x %= mod
    while n:
        if n & 1:
            result = result * x % mod         # keep every number below mod
        x = x * x % mod
        n >>= 1
    return result

Read the bits of n from the lowest one. 13 is 1101 in binary, so x^13 = x^1 · x^4 · x^8: three multiplications into the result and four squarings, not twelve multiplications. Python's built-in pow(x, n, mod) is the modular version.

Simulating 32-bit limits

Use it when: the statement says "assume 32-bit signed integers", "return 0 if it overflows" or "clamp to the range".

INT_MAX, INT_MIN = 2**31 - 1, -(2**31)


def reverse_digits(x: int) -> int:
    """Reverse the digits of x; return 0 when the result leaves the signed 32-bit range."""
    sign = -1 if x < 0 else 1
    x = abs(x)                                # work on a non-negative number: no floor-division surprises
    reversed_x = 0
    while x:
        x, digit = divmod(x, 10)
        reversed_x = reversed_x * 10 + digit  # Python never overflows here ...
    reversed_x *= sign
    if not INT_MIN <= reversed_x <= INT_MAX:  # ... so we check the range ourselves, once, at the end
        return 0
    return reversed_x


def divide_toward_zero(a: int, b: int) -> int:
    """Like C and Java: -7 / 2 is -3. Python's -7 // 2 is -4 because // rounds down."""
    q = abs(a) // abs(b)
    return q if (a < 0) == (b < 0) else -q

To clamp instead of returning 0, use max(INT_MIN, min(INT_MAX, value)). The limits are 2³¹ − 1 = 2147483647 and −2³¹ = −2147483648; there is one more negative value than positive, which matters for abs(INT_MIN).

Cycle detection: a set of seen values, or slow and fast pointers

Use it when: a process applies the same rule again and again (digit sums, next pointers, an array used as a linked list) and might loop instead of ending.

def ends_at_goal(start, step, goal) -> bool:
    """Follow x -> step(x). True if we reach goal, False if we loop forever instead."""
    seen = set()
    x = start
    while x != goal and x not in seen:        # a value seen twice means a cycle
        seen.add(x)
        x = step(x)
    return x == goal


def ends_at_goal_floyd(start, step, goal) -> bool:
    """Same answer with O(1) memory (the goal must repeat itself: step(goal) == goal)."""
    slow, fast = start, step(start)           # fast starts one step ahead so the loop test is not true at once
    while fast != goal and slow != fast:
        slow = step(slow)                     # tortoise: one step
        fast = step(step(fast))               # hare: two steps; inside a cycle it laps the tortoise
    return fast == goal

The set is the easy version and costs one entry per distinct value. Floyd's two pointers need no memory: inside a cycle the fast pointer gains one position per round, so the two must meet. Test for the goal first, because a happy chain also ends with the pointers meeting (both sit on 1).

Common mistakes

  • Rotating by writing cells into the same matrix while you still need the old values. Swap pairs, or move four cells in a cycle with one temporary. And matrix = new_matrix only rebinds the local name, so the caller still holds the old list; assign into it with matrix[:] = new_matrix (which does cost O(n²) extra memory).
  • Transposing with for c in range(n) instead of range(r + 1, n): every pair is swapped twice, which undoes the work and leaves the matrix unchanged.
  • [[0] * n] * m builds m references to the same row list, so changing one cell changes a whole column. Write [[0] * n for _ in range(m)].
  • Spiral and layer walks on a single row or a single column: without the top <= bottom and left <= right checks before the last two edges, the leftover row or column is collected twice.
  • Python integers never overflow, so a "32-bit" rule in the statement is silently ignored unless you check it. // and % also round toward minus infinity (-7 // 2 is -4), unlike C and Java, which round toward zero; take abs first and put the sign back.

Python tips

  • divmod(a, b) returns (a // b, a % b). To turn a digit character back into a number use int(ch) or ord(ch) - ord('0'); "3" * "4" is a TypeError.
  • list(zip(*matrix)) transposes (the new rows are tuples). matrix[::-1] and row[::-1] return reversed copies, while matrix.reverse() and row.reverse() reverse in place.
  • pow(x, n, mod) is built-in fast modular exponentiation, and pow(x, -1, mod) is the modular inverse (Python 3.8+).
  • Python 3.11 and later refuse to convert a string of more than 4300 digits with int() (a safety limit). collections.Counter with tuple keys, such as (x, y), is a tidy way to count points.
