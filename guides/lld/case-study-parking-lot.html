Case study: parking lot

The parking lot is the canonical LLD problem because a small domain exercises every core skill: clarifying scope, turning nouns into entities, choosing enums over class hierarchies, putting the rules that vary (allocation, pricing, payment) behind strategies, and keeping spot allocation correct when two gates act at once. The problem, and the questions that shape it

Design a parking lot. It has several floors with spots of different sizes. Vehicles of different types enter through entry gates, get a ticket and a spot, and pay at an exit gate for the time they stayed.

The parking lot is the canonical LLD problem because a small domain exercises every core skill: turning a vague statement into rules, choosing between enums and class hierarchies, finding the rules that vary and putting each behind an interface, and keeping a shared resource consistent when two gates act at once. The statement leaves almost every rule open, so the first five minutes decide how good the design can be.

Clarifying questions for a parking lot

RuleAssumption to write in the scope block
Vehicle typesmotorcycle, car, truck
Fita vehicle fits any spot at least as big as it needs: motorcycle → any, car → compact or large, truck → large only
Allocationbest fit: the smallest size that fits, nearest the entrance within that size
Gatesseveral entry and exit gates at once, so choosing and occupying a spot must be one atomic step
Pricingper started hour by vehicle type (₹20 / ₹40 / ₹100), the first 10 minutes free
Paymentcash or card; a declined card changes nothing and the barrier stays closed
Money and timeinteger paise; the clock is injected
Full lotrefuse at the gate with a clear error
Eight rules from ten questions. Each one becomes a line of code or a test, and most interview twists change one of these rows.

What is being tested: whether you find the rules that vary (which spot, what price, how to pay) and put each behind a small interface, while the core (spot, ticket, lot) stays small and correct, including when two gates act at once. A strong opening: 'Let me pin down the fit rule, the allocation policy, pricing and how many gates run in parallel; those four decide the design. I'll model vehicle and spot types as enums, put allocation, pricing and payment behind strategies, and make spot allocation atomic.'

Spot allocation, simulated

▶ Video lesson: Nearest-first or best fit? 4:14 · 8 scenes · narrated, pause anytime and explore

Two reasonable rules give different lots after an hour of traffic:

  • Nearest-first gives every vehicle the free spot closest to the entrance that it fits in. Short walks, simple code, but a car happily takes a large spot when that is nearest, and the next truck finds no room.
  • Best fit tries the smallest spot size that fits first, nearest within that size, and moves up a size only when it must. Large spots stay free for large vehicles; the price is that some cars walk further.

Step through both on the same lot. The first two scenarios show every spot the search examines; the last two run five arrivals and show only the decisions.

Where does the next vehicle go?

Rows are floors and columns are distance from the entrance. Blue cells are large spots, purple motorcycle spots, faded cells are taken. Watch the scan marker and the free counts.

StrategyPicksGainsCosts
Nearest-firstthe nearest free spot that fitsshortest walks; simplest codesmall vehicles use up large spots; trucks get refused early
Best fitthe smallest fitting size, nearest within itlarge spots stay for large vehiclessome cars walk further or go up a floor
Per-floor or per-gatethe nearest spot to the gate the car usedfair with several entrancesneeds a distance per gate, not one per spot
Best fit is the usual default. The decision is the operator's, which is why it is a strategy and not an if.

Both strategies above scan every spot, which is O(n) per arrival: fine for a few hundred spots. For a lot with thousands of spots and a busy gate, keep one min-heap of free spots per size, keyed by (floor, distance), so allocating is a pop and freeing is a push, O(log n) each (see Heap / Priority Queue). The price is a second copy of the occupancy that must stay in step with the spots, so add it only when the scan is measurably slow.

Best fit in O(log n): a heap of free spots per size

import heapq


class HeapBestFit:
    """An index of free spots. The service calls take() on entry and give_back() on exit, inside its lock."""

    def __init__(self, spots: list[ParkingSpot]):
        self._free: dict[SpotSize, list] = {size: [] for size in SpotSize}
        for s in spots:
            if s.is_free:
                self.give_back(s)

    def take(self, vehicle: Vehicle) -> ParkingSpot | None:
        for size in SpotSize:                                    # smallest size first: best fit
            if size.value >= vehicle.min_spot.value and self._free[size]:
                *_, spot = heapq.heappop(self._free[size])       # nearest spot of that size
                return spot
        return None

    def give_back(self, spot: ParkingSpot) -> None:
        # spot_id breaks ties, so heapq never has to compare two ParkingSpot objects
        heapq.heappush(self._free[spot.size], (spot.floor, spot.distance, spot.spot_id, spot))
Stateful, unlike the scanning strategies: it is an index the service must keep in sync, which is the trade-off to mention.

Parking lot in Python

Enums for the closed sets, dataclasses for the entities. ParkingSpot guards its own state: occupy refuses a taken or too-small spot, whatever the caller believes.

from __future__ import annotations

from dataclasses import dataclass
from datetime import datetime
from enum import Enum


class ParkingError(Exception):
    """A parking rule was broken; the message says which."""


class LotFullError(ParkingError):
    """No free spot fits this vehicle."""


class PaymentError(ParkingError):
    """The payment was declined; nothing changed."""


class SpotSize(Enum):                   # ordered values: a vehicle fits any spot at least as big as it needs
    MOTORCYCLE = 1
    COMPACT = 2
    LARGE = 3


class VehicleType(Enum):
    MOTORCYCLE = "motorcycle"
    CAR = "car"
    TRUCK = "truck"


MIN_SPOT = {VehicleType.MOTORCYCLE: SpotSize.MOTORCYCLE,
            VehicleType.CAR: SpotSize.COMPACT,
            VehicleType.TRUCK: SpotSize.LARGE}


@dataclass(frozen=True)
class Vehicle:
    plate: str
    kind: VehicleType

    @property
    def min_spot(self) -> SpotSize:
        return MIN_SPOT[self.kind]


@dataclass
class ParkingSpot:
    spot_id: str                        # "F0-C02": floor 0, compact, second from the entrance
    floor: int
    size: SpotSize
    distance: int                       # position from the entrance on its floor; smaller is nearer
    plate: str | None = None            # who is parked here, if anyone

    @property
    def is_free(self) -> bool:
        return self.plate is None

    def fits(self, vehicle: Vehicle) -> bool:
        return self.size.value >= vehicle.min_spot.value

    def occupy(self, vehicle: Vehicle) -> None:
        if not self.is_free:
            raise ParkingError(f"{self.spot_id} is already taken")
        if not self.fits(vehicle):
            raise ParkingError(f"a {vehicle.kind.value} does not fit {self.spot_id}")
        self.plate = vehicle.plate

    def vacate(self) -> None:
        self.plate = None


@dataclass
class Floor:
    number: int
    spots: list[ParkingSpot]


class ParkingLot:
    """The physical layout. It knows where the spots are, not who should get which."""

    def __init__(self, floors: list[Floor]):
        self.floors = floors
        self._by_id = {s.spot_id: s for f in floors for s in f.spots}

    @classmethod
    def from_layout(cls, layout: list[str]) -> ParkingLot:
        """One string per floor, nearest spot first: 'MCCL' = motorcycle, compact, compact, large."""
        size = {"M": SpotSize.MOTORCYCLE, "C": SpotSize.COMPACT, "L": SpotSize.LARGE}
        return cls([Floor(f, [ParkingSpot(f"F{f}-{ch}{d + 1:02d}", f, size[ch], d) for d, ch in enumerate(row)])
                    for f, row in enumerate(layout)])

    def spots(self) -> list[ParkingSpot]:
        return list(self._by_id.values())

    def spot(self, spot_id: str) -> ParkingSpot:
        return self._by_id[spot_id]

    def free_counts(self) -> dict[SpotSize, int]:
        return {size: sum(1 for s in self._by_id.values() if s.size is size and s.is_free) for size in SpotSize}


class TicketStatus(Enum):
    ACTIVE = "active"                   # issued at entry
    PAID = "paid"                       # charged; the car may leave
    CLOSED = "closed"                   # the car has left and the spot is free


@dataclass
class Ticket:
    ticket_id: str
    plate: str
    kind: VehicleType
    spot_id: str
    entry_time: datetime
    status: TicketStatus = TicketStatus.ACTIVE
    amount_paid: int = 0                # integer paise
    exit_time: datetime | None = None


@dataclass(frozen=True)
class Payment:
    ticket_id: str
    amount: int
    method: str
    reference: str

Three small interfaces, each with two implementations. None of them stores state, so each can be tested with a handful of spots and no service.

from __future__ import annotations

import math
from datetime import datetime
from typing import Callable, Iterable, Protocol


# --- allocation: which free spot does this vehicle get? ------------------------------------
class SpotAllocationStrategy(Protocol):
    def choose(self, spots: Iterable[ParkingSpot], vehicle: Vehicle) -> ParkingSpot | None: ...


class NearestFirst:
    """The free spot nearest the entrance that the vehicle fits in, whatever its size."""

    def choose(self, spots: Iterable[ParkingSpot], vehicle: Vehicle) -> ParkingSpot | None:
        fitting = [s for s in spots if s.is_free and s.fits(vehicle)]
        return min(fitting, key=lambda s: (s.floor, s.distance), default=None)


class BestFit:
    """The smallest size that fits, nearest first within that size: large spots stay free for large vehicles."""

    def choose(self, spots: Iterable[ParkingSpot], vehicle: Vehicle) -> ParkingSpot | None:
        fitting = [s for s in spots if s.is_free and s.fits(vehicle)]
        return min(fitting, key=lambda s: (s.size.value, s.floor, s.distance), default=None)


# --- pricing: how much does this stay cost? ---------------------------------------------------
class PricingStrategy(Protocol):
    def price(self, ticket: Ticket, exit_time: datetime) -> int: ...


class HourlyPricing:
    """A rate per started hour for each vehicle type. Stays within the grace period are free."""

    def __init__(self, hourly: dict[VehicleType, int], grace_minutes: int = 10):
        self.hourly, self.grace_minutes = dict(hourly), grace_minutes

    def price(self, ticket: Ticket, exit_time: datetime) -> int:
        minutes = (exit_time - ticket.entry_time).total_seconds() / 60
        if minutes <= self.grace_minutes:
            return 0
        return math.ceil(minutes / 60) * self.hourly[ticket.kind]


class FlatRatePricing:
    """One price per visit for each vehicle type: event days, airport drop-off zones."""

    def __init__(self, flat: dict[VehicleType, int]):
        self.flat = dict(flat)

    def price(self, ticket: Ticket, exit_time: datetime) -> int:
        return self.flat[ticket.kind]


# --- payment: the outside world, behind an interface ----------------------------------------
class PaymentProcessor(Protocol):
    method: str

    def charge(self, amount: int, ticket_id: str) -> str: ...     # returns a reference; raises PaymentError


class CashPayment:
    method = "cash"

    def charge(self, amount: int, ticket_id: str) -> str:
        return f"CASH-{ticket_id}"


class CardPayment:
    method = "card"

    def __init__(self, gateway: Callable[[int, str], str]):
        self._gateway = gateway             # the bank's API, injected so tests can approve or decline

    def charge(self, amount: int, ticket_id: str) -> str:
        return self._gateway(amount, ticket_id)

The use cases. park and exit share one lock because both change occupancy; pay charges before it changes anything. The gates are thin adapters around the service.

from __future__ import annotations

import itertools
import threading
from datetime import datetime
from typing import Callable, Iterator, Protocol


class TicketRepository(Protocol):
    def add(self, ticket: Ticket) -> None: ...
    def get(self, ticket_id: str) -> Ticket: ...
    def active_for(self, plate: str) -> Ticket | None: ...


class InMemoryTicketRepository:
    def __init__(self) -> None:
        self._tickets: dict[str, Ticket] = {}

    def add(self, ticket: Ticket) -> None:
        self._tickets[ticket.ticket_id] = ticket

    def get(self, ticket_id: str) -> Ticket:
        if ticket_id not in self._tickets:
            raise ParkingError(f"unknown ticket {ticket_id}")
        return self._tickets[ticket_id]

    def active_for(self, plate: str) -> Ticket | None:
        return next((t for t in self._tickets.values()
                     if t.plate == plate and t.status is not TicketStatus.CLOSED), None)


class ParkingService:
    """The use cases: park, quote, pay, exit. Rules that vary are delegated to the strategies."""

    def __init__(self, lot: ParkingLot, tickets: TicketRepository, allocation: SpotAllocationStrategy,
                 pricing: PricingStrategy, clock: Callable[[], datetime] = datetime.now,
                 ids: Iterator[str] | None = None):
        self._lot, self._tickets = lot, tickets
        self._allocation, self._pricing, self._clock = allocation, pricing, clock
        self._ids = ids or (f"T{n}" for n in itertools.count(1))
        self._lock = threading.Lock()       # guards occupancy: choose + occupy must be one indivisible step

    def park(self, vehicle: Vehicle) -> Ticket:
        with self._lock:                    # two entry gates may call park() at the same moment
            if self._tickets.active_for(vehicle.plate):
                raise ParkingError(f"{vehicle.plate} is already inside")
            spot = self._allocation.choose(self._lot.spots(), vehicle)
            if spot is None:
                raise LotFullError(f"no free spot fits a {vehicle.kind.value}")
            spot.occupy(vehicle)
            ticket = Ticket(next(self._ids), vehicle.plate, vehicle.kind, spot.spot_id, self._clock())
            self._tickets.add(ticket)
            return ticket

    def quote(self, ticket_id: str) -> int:
        return self._pricing.price(self._tickets.get(ticket_id), self._clock())

    def pay(self, ticket_id: str, processor: PaymentProcessor) -> Payment:
        ticket = self._tickets.get(ticket_id)
        if ticket.status is not TicketStatus.ACTIVE:
            raise ParkingError(f"{ticket_id} is {ticket.status.value}, not active")
        amount = self._pricing.price(ticket, self._clock())
        reference = processor.charge(amount, ticket_id)      # a decline raises: the ticket stays ACTIVE
        ticket.status, ticket.amount_paid = TicketStatus.PAID, amount
        return Payment(ticket_id, amount, processor.method, reference)

    def exit(self, ticket_id: str) -> Ticket:
        ticket = self._tickets.get(ticket_id)
        if ticket.status is not TicketStatus.PAID:
            raise ParkingError(f"{ticket_id} must be paid before the barrier opens")
        with self._lock:
            self._lot.spot(ticket.spot_id).vacate()
        ticket.status, ticket.exit_time = TicketStatus.CLOSED, self._clock()
        return ticket


class EntryGate:
    """Hardware adapter: reads the plate, prints the ticket, opens the barrier only on success."""

    def __init__(self, gate_id: str, service: ParkingService):
        self.gate_id, self._service = gate_id, service

    def admit(self, vehicle: Vehicle) -> Ticket:
        return self._service.park(vehicle)


class ExitGate:
    def __init__(self, gate_id: str, service: ParkingService):
        self.gate_id, self._service = gate_id, service

    def release(self, ticket_id: str, processor: PaymentProcessor) -> Payment:
        payment = self._service.pay(ticket_id, processor)
        self._service.exit(ticket_id)
        return payment

One test per rule, a fake clock for exact durations, fake card gateways for approvals and declines, and a concurrency test that fails if the lock is removed (the slow strategy widens the race window).

import time
from concurrent.futures import ThreadPoolExecutor
from datetime import datetime, timedelta

import pytest

RATES = {VehicleType.MOTORCYCLE: 2000, VehicleType.CAR: 4000, VehicleType.TRUCK: 10000}   # paise per started hour


class FakeClock:
    def __init__(self, start: datetime):
        self.now = start

    def __call__(self) -> datetime:
        return self.now

    def advance(self, **delta: float) -> None:
        self.now += timedelta(**delta)


def build(layout=("MCCLC", "CCL"), allocation=None):
    clock = FakeClock(datetime(2026, 1, 1, 9, 5))
    lot = ParkingLot.from_layout(list(layout))
    service = ParkingService(lot, InMemoryTicketRepository(), allocation or BestFit(), HourlyPricing(RATES), clock)
    return service, lot, clock


def car(plate="KA01AB1234"):
    return Vehicle(plate, VehicleType.CAR)


def approve(amount, ticket_id):
    return f"AUTH-{ticket_id}"


def decline(amount, ticket_id):
    raise PaymentError("card declined")


def test_car_gets_the_nearest_compact_spot():
    service, _, _ = build()
    assert service.park(car()).spot_id == "F0-C02"


def test_best_fit_keeps_the_large_spot_for_a_truck():
    service, _, _ = build(layout=("CL",))
    service.park(car("A"))
    assert service.park(Vehicle("T", VehicleType.TRUCK)).spot_id == "F0-L02"


def test_nearest_first_wastes_the_large_spot():

    assert service.park(car("A")).spot_id == "F0-L01"

    service.park(car("A"))
    with pytest.raises(LotFullError):
        service.park(car("B"))

def test_the_same_plate_cannot_enter_twice():

    service.park(car())

Vehicle type: a class per type, or an enum and a table?

A subclass per vehicle type

Three classes whose only job is to return a constant. Pricing still needs a rate per type, so isinstance checks or a dict keyed by class appear elsewhere.

An enum and a table

Adding a bus is one enum value, one row in MIN_SPOT and one rate. The day a type needs its own behaviour, give that behaviour a class or a policy.

'Why not a class per vehicle?' A strong answer: 'Because the types differ only in data, which spot sizes they fit and what they pay. An enum and a fit table keep that data in one place, and adding a bus is a value and a row. If one type starts to behave differently, say emergency vehicles skip payment, I would model that behaviour as a policy rather than build a hierarchy for every vehicle.'

Reservations

Give the spot two fields, reserved_for and reserved_until, and change one property:

@property
def is_free(self) -> bool:
    return self.plate is None and self.reserved_for is None    # every strategy now skips reserved spots

reserve(vehicle, arrive_by) chooses a spot with the same strategy and marks it until arrive_by plus a grace period. park uses the reserved spot when the plate has one. No-shows expire lazily at the start of reserve and park, inside the lock, so there is no timer thread to race with. If the business allows it, reserve capacity (a count per size) instead of a specific spot: simpler, and it never strands a spot.

Two gates allocating at once

One lot-wide lock is the simplest correct answer in one process, and it is what the implementation does. The alternatives are an atomic claim per spot with a retry (the third scenario of the simulation below), or, when several servers run the gates, letting the database arbitrate in one statement:

UPDATE spots SET plate = %(plate)s
WHERE spot_id = (
    SELECT spot_id FROM spots
    WHERE plate IS NULL AND size >= %(need)s
    ORDER BY size, floor, distance
    LIMIT 1
    FOR UPDATE SKIP LOCKED      -- pass over rows another gate is claiming right now
)
RETURNING spot_id;              -- no row back: the lot is full for this vehicle

Lost ticket

The driver has no ticket id, so look the ticket up by plate (active_for(plate) already exists) and price it with a LostTicketPricing decorator: the normal price or a fixed maximum, whichever is higher. A flag on the ticket records it for audit; no new state is needed.

Pay at a station, then exit

Payment and exit are already separate methods. Record paid_at; at the exit gate, if more than 15 minutes have passed since payment, price the extra time and charge it before the barrier opens. The ticket states stay the same.

Two gates, one free spot

Allocation is check-then-act on shared state: find a free spot, then occupy it. Two gates that interleave between those steps both pick the same spot. It is the same race as two users booking one cinema seat, covered in depth (locks, compare-and-swap, database guards, idempotency) in Concurrency & thread safety. What to notice

  • The base design absorbed both twists without a new hierarchy: two fields on ParkingSpot, one on Vehicle, one on Ticket, one allocation strategy and one pricing decorator.
  • The sort key (spot.charger != vehicle.electric, size, floor, distance) encodes both EV rules in one line: matching spots first, then best fit.
  • is_free treats a reserved spot as taken, so the allocation strategy contains no reservation logic at all.
  • No-shows expire lazily at the start of reserve and park, inside the lock: no timer thread, nothing to race with.
  • pay charges before it changes the ticket, and exit refuses an unpaid ticket, so a declined card can never open the barrier.
  • Deliberately missing: distances per gate, a no-show fee, monthly passes, persistence (a repository class per collection), and a database-backed claim for several servers.
"""Parking lot with EV charging and reservations: reference solution (about 75 minutes).

In scope: floors of motorcycle/compact/large spots, some compact spots with chargers; entry and exit gates; best-fit
allocation; hourly pricing by vehicle type with a grace period; a charging surcharge; cash and card payment;
reservations held until 15 minutes after the promised arrival.
Out of scope: UI, persistence, pay stations, monthly passes, lost tickets.
Assumptions: one process; a lock makes allocation atomic; money in integer paise; the clock is injected.
"""
from __future__ import annotations

import itertools
import math
import threading
from contextlib import contextmanager
from dataclasses import dataclass
from datetime import datetime, timedelta
from enum import Enum
from typing import Callable, Iterable, Protocol

RESERVATION_GRACE = timedelta(minutes=15)


class ParkingError(Exception):
    """A parking rule was broken; the message says which."""


class LotFullError(ParkingError):
    """No free spot fits this vehicle."""


class PaymentError(ParkingError):
    """The payment was declined; nothing changed."""


class SpotSize(Enum):
    MOTORCYCLE = 1
    COMPACT = 2
    LARGE = 3


class VehicleType(Enum):
    MOTORCYCLE = "motorcycle"
    CAR = "car"
    TRUCK = "truck"


MIN_SPOT = {VehicleType.MOTORCYCLE: SpotSize.MOTORCYCLE, VehicleType.CAR: SpotSize.COMPACT,
            VehicleType.TRUCK: SpotSize.LARGE}


@dataclass(frozen=True)
class Vehicle:
    plate: str
    kind: VehicleType
    electric: bool = False


@dataclass
class ParkingSpot:
    spot_id: str
    floor: int
    size: SpotSize
    distance: int
    charger: bool = False
    plate: str | None = None
    reserved_for: str | None = None
    reserved_until: datetime | None = None

    @property
    def is_free(self) -> bool:                       # free means nobody is parked here and nobody is expected
        return self.plate is None and self.reserved_for is None

    def fits(self, vehicle: Vehicle) -> bool:
        return self.size.value >= MIN_SPOT[vehicle.kind].value

    def reserve(self, plate: str, until: datetime) -> None:
        if not self.is_free:
            raise ParkingError(f"{self.spot_id} is not free")
        self.reserved_for, self.reserved_until = plate, until

    def release_reservation(self) -> None:
        self.reserved_for, self.reserved_until = None, None

    def occupy(self, vehicle: Vehicle) -> None:
        if self.plate is not None or self.reserved_for not in (None, vehicle.plate):
            raise ParkingError(f"{self.spot_id} is not available to {vehicle.plate}")
        if not self.fits(vehicle):
            raise ParkingError(f"a {vehicle.kind.value} does not fit {self.spot_id}")
        self.plate = vehicle.plate
        self.release_reservation()

    def vacate(self) -> None:
        self.plate = None


class ParkingLot:
    def __init__(self, layout: list[str]):
        """One string per floor, nearest first. M motorcycle, C compact, E compact with a charger, L large."""
        size = {"M": SpotSize.MOTORCYCLE, "C": SpotSize.COMPACT, "E": SpotSize.COMPACT, "L": SpotSize.LARGE}
        self._spots = {f"F{f}-{ch}{d + 1:02d}": ParkingSpot(f"F{f}-{ch}{d + 1:02d}", f, size[ch], d, charger=ch == "E")
                       for f, row in enumerate(layout) for d, ch in enumerate(row)}

    def spots(self) -> list[ParkingSpot]:
        return list(self._spots.values())

    def spot(self, spot_id: str) -> ParkingSpot:
        return self._spots[spot_id]


class TicketStatus(Enum):
    ACTIVE = "active"
    PAID = "paid"
    CLOSED = "closed"


@dataclass
class Ticket:
    ticket_id: str
    plate: str
    kind: VehicleType
    spot_id: str
    entry_time: datetime
    charging: bool = False
    status: TicketStatus = TicketStatus.ACTIVE
    amount_paid: int = 0


@dataclass(frozen=True)
class Reservation:
    reservation_id: str
    plate: str
    spot_id: str
    until: datetime


# --- strategies --------------------------------------------------------------------------------
class SpotAllocationStrategy(Protocol):
    def choose(self, spots: Iterable[ParkingSpot], vehicle: Vehicle) -> ParkingSpot | None: ...


class EvAwareBestFit:
    """Best fit, plus: electric vehicles prefer chargers; everyone else uses a charger only as a last resort."""

    def choose(self, spots: Iterable[ParkingSpot], vehicle: Vehicle) -> ParkingSpot | None:
        fitting = [s for s in spots if s.is_free and s.fits(vehicle)]
        return min(fitting, key=lambda s: (s.charger != vehicle.electric, s.size.value, s.floor, s.distance),
                   default=None)


class PricingStrategy(Protocol):
    def price(self, ticket: Ticket, exit_time: datetime) -> int: ...


def started_hours(ticket: Ticket, exit_time: datetime) -> int:
    return math.ceil((exit_time - ticket.entry_time).total_seconds() / 3600)


class HourlyPricing:
    def __init__(self, hourly: dict[VehicleType, int], grace_minutes: int = 10):
        self.hourly, self.grace = dict(hourly), timedelta(minutes=grace_minutes)

    def price(self, ticket: Ticket, exit_time: datetime) -> int:
        if exit_time - ticket.entry_time <= self.grace:
            return 0
        return started_hours(ticket, exit_time) * self.hourly[ticket.kind]


class ChargingSurcharge:
    """A decorator over any pricing strategy: adds a per-hour fee when the ticket was charging."""

    def __init__(self, inner: PricingStrategy, per_hour: int):
        self.inner, self.per_hour = inner, per_hour

    def price(self, ticket: Ticket, exit_time: datetime) -> int:
        extra = started_hours(ticket, exit_time) * self.per_hour if ticket.charging else 0
        return self.inner.price(ticket, exit_time) + extra


class PaymentProcessor(Protocol):
    method: str

    def charge(self, amount: int, ticket_id: str) -> str: ...


class CardPayment:
    method = "card"

    def __init__(self, gateway: Callable[[int, str], str]):
        self._gateway = gateway

    def charge(self, amount: int, ticket_id: str) -> str:
        return self._gateway(amount, ticket_id)


# --- service ------------------------------------------------------------------------------------
class ParkingService:
    def __init__(self, lot: ParkingLot, allocation: SpotAllocationStrategy, pricing: PricingStrategy,
                 clock: Callable[[], datetime] = datetime.now):
        self._lot, self._allocation, self._pricing, self._clock = lot, allocation, pricing, clock
        self._tickets: dict[str, Ticket] = {}                # in-memory repositories
        self._reservations: dict[str, Reservation] = {}      # plate -> live reservation
        self._ids = itertools.count(1)
        self._lock = threading.Lock()                        # allocation, reservation and release are one step each

    def reserve(self, vehicle: Vehicle, arrive_by: datetime) -> Reservation:
        with self._lock:
            self._expire_reservations()
            if vehicle.plate in self._reservations or self._active_ticket(vehicle.plate):
                raise ParkingError(f"{vehicle.plate} already has a reservation or is inside")
            spot = self._allocation.choose(self._lot.spots(), vehicle)
            if spot is None:
                raise LotFullError(f"nothing to reserve for a {vehicle.kind.value}")
            spot.reserve(vehicle.plate, arrive_by + RESERVATION_GRACE)
            res = Reservation(f"R{next(self._ids)}", vehicle.plate, spot.spot_id, spot.reserved_until)
            self._reservations[vehicle.plate] = res
            return res

    def park(self, vehicle: Vehicle) -> Ticket:
        with self._lock:
            self._expire_reservations()
            if self._active_ticket(vehicle.plate):
                raise ParkingError(f"{vehicle.plate} is already inside")
            res = self._reservations.pop(vehicle.plate, None)
            spot = self._lot.spot(res.spot_id) if res else self._allocation.choose(self._lot.spots(), vehicle)
            if spot is None:
                raise LotFullError(f"no free spot fits a {vehicle.kind.value}")
            spot.occupy(vehicle)
            ticket = Ticket(f"T{next(self._ids)}", vehicle.plate, vehicle.kind, spot.spot_id, self._clock(),
                            charging=spot.charger and vehicle.electric)
            self._tickets[ticket.ticket_id] = ticket
            return ticket

    def pay(self, ticket_id: str, processor: PaymentProcessor) -> int:
        ticket = self._ticket(ticket_id)
        if ticket.status is not TicketStatus.ACTIVE:
            raise ParkingError(f"{ticket_id} is {ticket.status.value}")
        amount = self._pricing.price(ticket, self._clock())
        processor.charge(amount, ticket_id)                  # raises PaymentError on a decline
        ticket.status, ticket.amount_paid = TicketStatus.PAID, amount
        return amount

    def exit(self, ticket_id: str) -> None:
        ticket = self._ticket(ticket_id)
        if ticket.status is not TicketStatus.PAID:
            raise ParkingError(f"{ticket_id} must be paid first")
        with self._lock:
            self._lot.spot(ticket.spot_id).vacate()
        ticket.status = TicketStatus.CLOSED

    def _expire_reservations(self) -> None:
        now = self._clock()
        for plate, res in list(self._reservations.items()):
            if res.until <= now:                             # a no-show: the spot goes back to the pool
                self._lot.spot(res.spot_id).release_reservation()
                del self._reservations[plate]

    def _active_ticket(self, plate: str) -> Ticket | None:
        return next((t for t in self._tickets.values() if t.plate == plate and t.status is not TicketStatus.CLOSED), None)

    def _ticket(self, ticket_id: str) -> Ticket:
        if ticket_id not in self._tickets:
            raise ParkingError(f"unknown ticket {ticket_id}")
        return self._tickets[ticket_id]

class FakeClock:
    def __init__(self, start: datetime):
        self.now = start

    def __call__(self) -> datetime:
        return self.now

    def advance(self, **delta: float) -> None:
        self.now += timedelta(**delta)


@contextmanager
def raises(error: type[Exception]):
    try:
        yield
    except error:
        return
    raise AssertionError(f"{error.__name__} was not raised")

    with raises(ParkingError):
        service.exit(ticket.ticket_id)
    clock.advance(minutes=50)
    assert service.pay(ticket.ticket_id, CardPayment(approve)) == 4000
    service.exit(ticket.ticket_id)
    assert lot.spot(ticket.spot_id).is_free


def test_reserved_spot_is_held_for_the_reserver():
    service, _, clock = build(layout=("CC",))
    res = service.reserve(Vehicle("R1", VehicleType.CAR), arrive_by=clock() + timedelta(hours=1))
    assert res.spot_id == "F0-C01"
    assert service.park(Vehicle("X", VehicleType.CAR)).spot_id == "F0-C02"   # walks past the held spot
    clock.advance(minutes=40)
    assert service.park(Vehicle("R1", VehicleType.CAR)).spot_id == "F0-C01"


def test_no_show_releases_the_spot():

A strong answer to 'design a parking lot': 'Spots come in three sizes and a vehicle fits any spot at least its size, so sizes and vehicle types are ordered enums and fitting is one comparison. A ParkingService runs the two use cases, park and exit. The three rules that vary sit behind strategies: allocation (best fit by default, so large spots stay for trucks), pricing (per started hour by type, with decorators for surcharges) and payment, which is charged before any state changes. Choosing and occupying a spot happens under one lock, because several gates run at once; across servers I would let the database claim the spot with a conditional update.'

Classic mistakes: a ParkingLot god class that allocates, prices, charges and prints; a subclass per vehicle that only returns constants; float money; datetime.now() inside the pricing code; allocation without a lock when the statement says gates; and freeing the spot before the charge succeeds.
