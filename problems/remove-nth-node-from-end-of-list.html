Remove Nth Node From End of List Medium

LeetCode #19 ↗
Status

Delete the n-th node counted from the end of a linked list, ideally in one pass.

Problem

You are given head, the first node of a linked list, and an integer n. Remove the n-th node from the end (n = 1 is the last node) and return the head of the resulting list.

n is always valid: 1 <= n <= length of the list. Removing the only node leaves an empty list.

Examples

Example 1
Input: head = [1, 2, 3, 4, 5], n = 2
Output: [1, 2, 3, 5]
Counting from the end: 5 is 1st, 4 is 2nd, so 4 goes.
Example 2
Input: head = [1], n = 1
Output: []
Example 3
Input: head = [1, 2], n = 2
Output: [2]
The 2nd from the end is the head itself.

Constraints

  • 1 <= number of nodes <= 30
  • 0 <= Node.val <= 100
  • 1 <= n <= number of nodes
  • follow-up: do it in one pass

Think first try before reading the solution

If you knew the length L, which node would it be counting from the front? How do you find L?
To delete a node you need the node before it, so you can write before.next = before.next.next. What if the node to delete is the head? A dummy node in front of the head gives even the head a 'before'.
One pass: move a fast pointer n nodes ahead of slow, then move both together until fast is on the last node. The fixed gap leaves slow right before the node to delete.

Key idea

Counting from the end is awkward because a singly linked list only walks forwards. One fix is two passes: count the length L, then walk L - n nodes. The neater fix is a ruler: two pointers that stay exactly n nodes apart. When the front pointer reaches the last node, the back pointer is n nodes behind it, which is exactly the node before the n-th from the end.

To delete a node you re-point the node before it (before.next = before.next.next). The head has no node before it, so put a dummy node (a placeholder) in front of the list and start both pointers there. Now deleting the head is the same operation as deleting any other node, and the answer is dummy.next.

Approaches from the obvious one to the one you want in an interview

Copy every node reference into a Python list. Negative indices count from the end, so the node before the target is nodes[-n - 1]. Re-point it past the target. If the target is the head (n equals the length), there is no node before it, so return head.next instead.

O(L) time, but O(L) extra memory for the array, and the head case needs its own branch.

Python

class Solution:
    def removeNthFromEnd(self, head: Optional[ListNode], n: int) -> Optional[ListNode]:
        nodes = []
        cur = head
        while cur:
            nodes.append(cur)
            cur = cur.next
        if n == len(nodes):                  # the target is the head
            return head.next
        before = nodes[-n - 1]               # the node just before the target
        before.next = before.next.next
        return head
Time O(L)Space O(L)

One pass to fill the array; the array holds all L references.

When to use: Only as a first idea; the pointer versions need no extra memory.

Pass 1 counts the length L. The target is then node L - n + 1 from the front, so the node before it is L - n steps after a dummy node placed in front of the head. Pass 2 walks those L - n steps and unlinks the next node.

O(L) time and O(1) memory. The only drawback is reading the list twice, which the follow-up asks you to avoid (think of a list arriving as a stream you can only read once).

Dry run

  1. [1, 2, 3, 4, 5], n = 2: pass 1 → L = 5
  2. pass 2: from the dummy, walk L - n = 3 steps → node 3
  3. 3.next = 3.next.next removes 4 → [1, 2, 3, 5]

Python

class Solution:
    def removeNthFromEnd(self, head: Optional[ListNode], n: int) -> Optional[ListNode]:
        length = 0
        cur = head
        while cur:                           # pass 1: count the nodes
            length += 1
            cur = cur.next
        dummy = ListNode(0, head)            # gives the head a node before it
        before = dummy
        for _ in range(length - n):          # pass 2: stop right before the target
            before = before.next
        before.next = before.next.next
        return dummy.next
Time O(L)Space O(1)

Two linear passes; a counter and two pointers.

When to use: Perfectly good; same complexity as the one-pass version, slightly easier to explain.

Start slow and fast on a dummy node in front of the head. Move fast alone n times, opening a gap of n nodes. Then move both one step at a time until fast.next is None, which means fast is on the last node. Because the gap is still n, slow is now right before the n-th node from the end: unlink it with slow.next = slow.next.next.

Same O(L) time and O(1) memory as two passes, but each node is reached once by the leading pointer. Starting on the dummy means removing the head needs no special case.

Dry run

  1. dummy → 1 → 2 → 3 → 4 → 5, n = 2: slow = fast = dummy
  2. move fast 2 times → fast on 2
  3. move both until fast.next is None: (1, 3), (2, 4), (3, 5)
  4. slow on 3 → 3.next = 5 → return dummy.next = [1, 2, 3, 5]

Python

class Solution:
    def removeNthFromEnd(self, head: Optional[ListNode], n: int) -> Optional[ListNode]:
        dummy = ListNode(0, head)
        slow = fast = dummy
        for _ in range(n):                   # open a gap of n nodes
            fast = fast.next
        while fast.next:                     # walk until fast is on the last node
            slow = slow.next
            fast = fast.next
        slow.next = slow.next.next           # slow is right before the target
        return dummy.next                    # the head may have been removed
Time O(L)Space O(1)

fast walks the list once; slow trails it. Two pointers of extra memory.

When to use: The answer to the one-pass follow-up.

Common mistakes

  • Deleting the head (n equals the length) without a dummy node: there is no node before it to re-point. With the dummy, return dummy.next, not head.
  • Off-by-one in the gap. With both pointers starting at the dummy, move fast exactly n times, then stop the joint walk when fast.next is None. (Alternatively move it n + 1 times and stop when fast is None.) Mixing the two conventions removes the wrong node.
  • Returning head after the head was removed returns the deleted node.
  • Stopping slow on the target instead of before it: in a singly linked list you cannot unlink a node from itself.

Python notes

  • dummy = ListNode(0, head) builds the placeholder and links it in one line.
  • slow.next = slow.next.next is the whole deletion. Python frees the removed node once nothing refers to it.
  • for _ in range(n): is the idiom for "do this n times" when the loop variable is not needed.
