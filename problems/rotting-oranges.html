Rotting Oranges Medium

LeetCode #994 ↗
Status

Count the minutes until rot has spread to every orange, or return -1 if some orange is never reached.

Problem

You are given an m × n grid where each cell is:

  • 0: empty,
  • 1: a fresh orange,
  • 2: a rotten orange.

Every minute, each fresh orange directly up, down, left or right of a rotten orange becomes rotten. Return the minimum number of minutes until no fresh orange is left. If some fresh orange can never rot, return -1. If there are no fresh oranges at the start, the answer is 0.

Examples

Example 1
Input: grid = [[2,1,1],[1,1,0],[0,1,1]]
Output: 4
Minute 1: (0,1), (1,0). Minute 2: (0,2), (1,1). Minute 3: (2,1). Minute 4: (2,2).
Example 2
Input: grid = [[2,1,1],[0,1,1],[1,0,1]]
Output: -1
The orange at (2,0) has only empty cells next to it, so rot never reaches it.
Example 3
Input: grid = [[0,2]]
Output: 0
There is no fresh orange, so no time is needed.

Constraints

  • 1 <= m, n <= 10
  • grid[i][j] is 0, 1 or 2

Think first try before reading the solution

Simulate one minute by hand. Which oranges rot? Only fresh ones touching an orange that was already rotten at the start of that minute.
Rescanning the whole grid every minute repeats work. The only oranges that can spread rot this minute are the ones that rotted last minute. Keep exactly those in a queue.
Put all the initially rotten oranges in one queue and run BFS one level at a time: each level is one minute. Count fresh oranges so you know at the end whether any were never reached.

Key idea

Rot spreads exactly like a BFS wave: at minute 1 it reaches every fresh orange one step from a rotten one, at minute 2 everything two steps away, and so on. When several oranges are rotten at the start, they all spread at the same time, so they all go into the queue before the search begins. That is multi-source BFS.

Process the queue one level at a time. The oranges in the queue at the start of a round are exactly the ones that rotted during the previous minute, and the round itself is one minute. Keep a count of fresh oranges: when it hits zero, the number of rounds so far is the answer. If the queue runs dry while the count is still above zero, some oranges are cut off by empty cells and the answer is -1.

Approaches from the obvious one to the one you want in an interview

Do what the statement describes. Each minute, scan the whole grid and collect every fresh orange that has a rotten neighbour. Rot them after the scan, so oranges that rot this minute cannot spread until the next one. Stop when a scan finds nothing to rot; then the answer is the number of minutes, or -1 if a fresh orange is left.

It is correct, but every minute costs a full scan of m · n cells, and a long winding line of oranges can take about m · n minutes to rot, so the worst case is O((m · n)²).

Dry run

  1. Example 1: minute 1's scan finds (0,1), (1,0) → rot them.
  2. Minute 2: (0,2), (1,1). Minute 3: (2,1). Minute 4: (2,2).
  3. Minute 5's scan finds nothing and no fresh orange is left → 4. Five full scans of 9 cells to rot 6 oranges.

Python

class Solution:
    def orangesRotting(self, grid: List[List[int]]) -> int:
        grid = [row[:] for row in grid]           # work on a copy
        rows, cols = len(grid), len(grid[0])
        minutes = 0
        while True:
            to_rot = []
            for r in range(rows):
                for c in range(cols):
                    if grid[r][c] != 1:
                        continue
                    for nr, nc in ((r + 1, c), (r - 1, c), (r, c + 1), (r, c - 1)):
                        if 0 <= nr < rows and 0 <= nc < cols and grid[nr][nc] == 2:
                            to_rot.append((r, c))     # judged on the grid as it was at the minute's start
                            break
            if not to_rot:                        # nothing changed: the spreading is over
                break
            for r, c in to_rot:                   # apply the whole minute at once
                grid[r][c] = 2
            minutes += 1
        still_fresh = any(cell == 1 for row in grid for cell in row)
        return -1 if still_fresh else minutes

Up to about m · n minutes, each scanning all m · n cells.

When to use: To check your understanding of the rules; fine for the 10 × 10 limit, but it does not scale.

Watch it run

Queue every rotten orange at the start and count the fresh ones. Then repeat while the queue is not empty and fresh oranges remain:

  1. one more minute passes;
  2. pop exactly the oranges that are in the queue right now (for _ in range(len(queue))), the ones that rotted last minute;
  3. each popped orange rots its fresh, not-yet-visited neighbours: mark them, decrease fresh, queue them.

Every orange is queued at most once, so the work is O(m · n). At the end fresh == 0 means the answer is the number of minutes; otherwise some orange was unreachable and the answer is -1.

Dry run

  1. Example 1: queue [(0,0)], fresh = 6.
  2. Minute 1: pop (0,0) → rots (1,0), (0,1). fresh = 4.
  3. Minute 2: pop (1,0) → rots (1,1); pop (0,1) → rots (0,2). fresh = 2.
  4. Minute 3: pop (1,1) → rots (2,1); pop (0,2) → nothing. fresh = 1.
  5. Minute 4: pop (2,1) → rots (2,2). fresh = 0 → stop, answer 4.

Python

class Solution:
    def orangesRotting(self, grid: List[List[int]]) -> int:
        rows, cols = len(grid), len(grid[0])
        queue = deque()
        fresh = 0
        for r in range(rows):
            for c in range(cols):
                if grid[r][c] == 2:
                    queue.append((r, c))          # every rotten orange spreads from minute 0
                elif grid[r][c] == 1:
                    fresh += 1
        visited = set(queue)                      # oranges that are already rotten
        minutes = 0
        while queue and fresh > 0:                # stop as soon as nothing is left to rot
            minutes += 1                          # one round of this loop = one minute
            for _ in range(len(queue)):           # exactly the oranges that rotted last minute
                r, c = queue.popleft()
                for nr, nc in ((r + 1, c), (r - 1, c), (r, c + 1), (r, c - 1)):
                    if (0 <= nr < rows and 0 <= nc < cols
                            and grid[nr][nc] == 1 and (nr, nc) not in visited):
                        visited.add((nr, nc))     # it rots now and spreads next minute
                        fresh -= 1
                        queue.append((nr, nc))
        return minutes if fresh == 0 else -1
Time O(m · n)Space O(m · n)

Each orange enters the queue once and checks 4 neighbours; the queue and visited hold at most m · n cells.

When to use: The interview answer: one pass, and the level loop makes 'minutes' explicit.

Watch it run

Skip the level loop. Store, for every orange the rot reaches, the minute it rots: rotten ones start at 0, and an orange reached from a neighbour gets that neighbour's minute + 1. Plain BFS order guarantees each orange is first reached at its earliest minute.

The answer is the largest minute stored, provided every fresh orange got one. This is the Walls and Gates pattern, and it also answers "when does each orange rot?" for free.

Python

class Solution:
    def orangesRotting(self, grid: List[List[int]]) -> int:
        rows, cols = len(grid), len(grid[0])
        minute = {}                               # orange -> minute it is rotten by
        queue = deque()
        for r in range(rows):
            for c in range(cols):
                if grid[r][c] == 2:
                    minute[(r, c)] = 0
                    queue.append((r, c))
        while queue:
            r, c = queue.popleft()
            for nr, nc in ((r + 1, c), (r - 1, c), (r, c + 1), (r, c - 1)):
                if (0 <= nr < rows and 0 <= nc < cols
                        and grid[nr][nc] == 1 and (nr, nc) not in minute):
                    minute[(nr, nc)] = minute[(r, c)] + 1    # first arrival = earliest minute
                    queue.append((nr, nc))
        fresh = sum(row.count(1) for row in grid)
        reached = len(minute) - sum(row.count(2) for row in grid)   # fresh oranges the rot got to
        return max(minute.values(), default=0) if reached == fresh else -1
Time O(m · n)Space O(m · n)

When to use: When you also need each orange's own rotting time, or prefer one flat loop over the level-by-level one.

Common mistakes

  • In the simulation, rotting oranges during the scan that is still reading the grid: an orange that rotted a moment ago then spreads in the same minute and the answer comes out too small. Decide the whole minute's changes first, then apply them.
  • Adding one minute for every BFS round, including the last round that rots nothing: the answer is one too big. Stop as soon as no fresh orange is left (the fresh > 0 loop condition).
  • Forgetting the -1 case: track how many fresh oranges remain and check it at the end.
  • Returning -1 when there are no fresh oranges at all. Nothing needs to rot, so the answer is 0, even with no rotten orange either.
  • Running a separate BFS from each rotten orange: rot spreads from all of them at once, so they must share one queue.

Python notes

  • for _ in range(len(queue)): evaluates len(queue) once, so oranges appended during the round wait for the next round.
  • The visited set stops an orange from being queued twice. Writing grid[r][c] = 2 instead does the same job without a set, but changes the caller's grid.
  • sum(row.count(1) for row in grid) counts the fresh oranges in one line.
  • max(minute.values(), default=0) avoids a ValueError when the dictionary is empty.

Follow-up questions

What an interviewer might ask next, and what changes.

  • Walls and Gates LC 286 — the same multi-source BFS, but each cell stores its own distance instead of sharing one clock.
  • 01 Matrix LC 542 — the distance from every cell to its nearest 0: queue all the zeros first, then spread.
  • Shortest Path in Binary Matrix LC 1091 — a single source and 8 directions; the BFS level at which the far corner is reached is the answer.
  • Network Delay Time LC 743 — a signal takes a different time along each edge, so BFS levels no longer equal time: use Dijkstra with a min-heap.
  • What if rot also spreads diagonally? — add the four diagonal offsets to the direction list; the BFS is otherwise unchanged.
  • Report the minute at which every orange rots — store minute[(r, c)] for each orange as it is queued, as in the third approach.
