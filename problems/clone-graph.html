Clone Graph Medium

LeetCode #133 ↗
Status

Build a complete, independent copy of a connected undirected graph from one of its nodes.

Problem

You are given one node of a connected, undirected graph. Each node has an integer val and a list neighbors of the nodes it is joined to:

class Node:
    def __init__(self, val=0, neighbors=None):
        self.val = val
        self.neighbors = neighbors if neighbors is not None else []

Return a deep copy of the whole graph: brand-new Node objects with the same values and the same connections, sharing no node with the original. If the graph is empty the input is None; return None.

The graph is written as an adjacency list: adj[i] lists the values of the neighbours of the node whose value is i + 1, and you are handed the node with value 1. Values are unique.

Examples

Example 1
Input: adj = [[2,4],[1,3],[2,4],[1,3]]
Output: [[2,4],[1,3],[2,4],[1,3]]
A square: 1–2, 2–3, 3–4, 4–1. The copy has the same shape but entirely new nodes.
Example 2
Input: adj = [[]]
Output: [[]]
One node with no neighbours.
Example 3
Input: adj = []
Output: []
An empty graph: the input node is None.

Constraints

  • 0 <= number of nodes <= 100
  • 1 <= Node.val <= 100, all values unique
  • no repeated edges and no self-loops
  • the graph is connected

Think first try before reading the solution

Copying a node is easy; the hard part is its neighbours. A neighbour may lead back to a node you are still copying (1 → 2 → 1). How do you avoid making a second copy of node 1?
Keep a dictionary from each original node to its copy. Before creating a copy, look it up; if it is there, reuse it.
Insert the new copy into the dictionary before you copy its neighbours. Then any path that comes back to this node finds the copy already waiting.

Key idea

A graph copy is a traversal that builds as it walks. Every time you meet an original node, you need its copy: created now if this is the first meeting, reused if you have met it before. A dictionary copies from original node to copy answers "have I met you, and who is your copy?" in O(1).

The dictionary also plays the part of the visited set. Because a node's copy is stored before its neighbours are explored, a cycle that leads back to it finds the copy in the dictionary and stops there. Each node is copied once and each neighbour reference is wired once, so the work is O(V + E).

Approaches from the obvious one to the one you want in an interview

Write clone(cur), which returns the copy of cur:

  1. If cur is already in copies, return that copy. Nothing new is created.
  2. Otherwise create Node(cur.val) and store it in copies right away.
  3. For each neighbour, append clone(neighbour) to the new node's neighbors.

Step 2 before step 3 is the whole trick. When the recursion goes round a cycle and comes back to cur, step 1 finds the copy and returns, so the walk always ends. Every node is created once and every neighbour reference is appended once.

Dry run

  1. Square [[2,4],[1,3],[2,4],[1,3]]. clone(1): create 1′; neighbours 2 and 4.
  2. clone(2): create 2′. Its neighbour 1 is in copies → append 1′. Then clone(3): create 3′.
  3. In clone(3): neighbour 2 is copied → append 2′. clone(4): create 4′; 1 and 3 are copied → append 1′, 3′.
  4. Unwinding: 3′ gets 4′, 2′ gets 3′, 1′ gets 2′. Finally 1's other neighbour 4 is copied → append 4′.
  5. Return 1′: 4 nodes created, 8 references wired.

Python

class Solution:
    def cloneGraph(self, node: Optional['Node']) -> Optional['Node']:
        copies = {}                                   # original node -> its copy (also our visited set)

        def clone(cur: 'Node') -> 'Node':
            if cur in copies:                         # met before: reuse the copy (this stops cycles)
                return copies[cur]
            copy = Node(cur.val)
            copies[cur] = copy                        # register BEFORE visiting the neighbours
            for nb in cur.neighbors:
                copy.neighbors.append(clone(nb))      # the copy of nb, made now or earlier
            return copy

        return clone(node) if node else None
Time O(V + E)Space O(V)

Each node is copied once and each of the 2E neighbour references is appended once. The dictionary holds V entries and the call stack can be V frames deep.

When to use: The usual answer: shortest, and the dictionary idea carries over to Copy List with Random Pointer.

Watch it run

Iterative version. Copy the start node, store it, and queue the original. Pop a node; for each neighbour that has no copy yet, create the copy and queue the neighbour. Whether the neighbour is new or not, append its copy to the popped node's copy.

A node gets its copy the moment it is discovered, so a key in copies means "already queued, never queue again": the dictionary is the visited set. No recursion, so no depth limit.

Dry run

  1. Square: create 1′, queue [1].
  2. Pop 1: 2 is new → create 2′, queue it, wire 1′ → 2′. 4 is new → create 4′, queue it, wire 1′ → 4′.
  3. Pop 2: 1 is copied → wire 2′ → 1′. 3 is new → create 3′, queue it, wire 2′ → 3′.
  4. Pop 4: wire 4′ → 1′ and 4′ → 3′. Pop 3: wire 3′ → 2′ and 3′ → 4′. Queue empty → return 1′.

Python

class Solution:
    def cloneGraph(self, node: Optional['Node']) -> Optional['Node']:
        if node is None:
            return None
        copies = {node: Node(node.val)}               # original -> copy; a key means "already discovered"
        queue = deque([node])
        while queue:
            cur = queue.popleft()
            for nb in cur.neighbors:
                if nb not in copies:                  # first sighting: make its copy and schedule it
                    copies[nb] = Node(nb.val)
                    queue.append(nb)
                copies[cur].neighbors.append(copies[nb])   # wire the copied edge cur′ → nb′
        return copies[node]
Time O(V + E)Space O(V)

Same counts as the DFS; the queue replaces the call stack.

When to use: When the graph could be deep enough to worry about recursion, or if you find the loop easier to follow.

Watch it run

Split the job in two so each part is simple. Pass 1 walks the graph (any traversal) and creates a bare copy of every node, filling copies. Pass 2 goes through the dictionary and rebuilds each copy's neighbour list by translating the original list through it: copy.neighbors = [copies[nb] for nb in original.neighbors].

Same O(V + E). It makes plain that cloning a graph is "copy the nodes, then translate the edges", at the price of walking the edges twice.

Python

class Solution:
    def cloneGraph(self, node: Optional['Node']) -> Optional['Node']:
        if node is None:
            return None
        copies = {node: Node(node.val)}               # pass 1: find every node and make a bare copy
        stack = [node]
        while stack:
            cur = stack.pop()
            for nb in cur.neighbors:
                if nb not in copies:
                    copies[nb] = Node(nb.val)
                    stack.append(nb)
        for original, copy in copies.items():         # pass 2: translate every edge through the map
            copy.neighbors = [copies[nb] for nb in original.neighbors]
        return copies[node]
Time O(V + E)Space O(V)

When to use: As a stepping stone when the one-pass versions feel like too much at once.

Common mistakes

  • Recursing into neighbours with no dictionary: the first cycle (1 → 2 → 1) makes the copying go on forever (RecursionError).
  • Storing the copy in the dictionary only after its neighbours are copied: a neighbour that points back finds nothing and copies the node again, and the same endless loop follows. Register first, recurse second.
  • Writing copy.neighbors = cur.neighbors: the copy then points at the original nodes, so it is not a deep copy. Every reference inside the copy must lead to another copy.
  • Keying the dictionary by val. It happens to work here because values are unique; key by the node object and it keeps working when they are not.
  • Forgetting the empty graph: node can be None.

Python notes

  • Objects are hashable by identity by default, so copies[cur] keys on this exact node, not on its value.
  • The annotation Optional['Node'] puts Node in quotes (a forward reference) so it still works when the class is defined after the method.
  • The tests turn the returned node back into an adjacency list and compare that. They cannot tell a real copy from the original graph, so make sure you never return node.
  • collections.deque gives the BFS version O(1) popleft().

Follow-up questions

What an interviewer might ask next, and what changes.

  • Copy List with Random Pointer LC 138 — the same original → copy dictionary on a linked list whose random pointers can point anywhere.
  • Clone Binary Tree With Random Pointer LC 1485 — a tree traversal plus random pointers that may point to nodes not copied yet: the dictionary is needed again.
  • Clone N-ary Tree LC 1490 — a tree has no cycles and every node has one parent, so plain recursion works with no dictionary at all.
  • What if the graph is directed? — nothing changes: neighbors are already one-way references, and the code copies exactly the references it sees.
  • What if the graph is disconnected and you get a list of all its nodes? — call the same clone on every node of the list with one shared dictionary; nodes already copied are skipped.
