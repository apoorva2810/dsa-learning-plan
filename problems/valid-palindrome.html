Valid Palindrome Easy

LeetCode #125 ↗
Status

Decide whether a string reads the same in both directions once case and non-alphanumeric characters are ignored.

Problem

You are given a string s. Clean it up in two steps:

  1. turn every uppercase letter into lowercase,
  2. drop every character that is not a letter or a digit (spaces, commas, colons, ...).

Return True if the cleaned string is a palindrome, meaning it reads the same from left to right as from right to left, and False otherwise.

If nothing is left after cleaning, the result is the empty string, which counts as a palindrome.

Examples

Example 1
Input: s = "A man, a plan, a canal: Panama"
Output: true
The cleaned string is "amanaplanacanalpanama", which is the same reversed.
Example 2
Input: s = "race a car"
Output: false
The cleaned string is "raceacar"; reversed it is "racaecar".
Example 3
Input: s = " "
Output: true
Nothing is left after removing the space, and the empty string is a palindrome.

Constraints

  • 1 <= len(s) <= 2 * 10^5
  • s consists only of printable ASCII characters

Think first try before reading the solution

Pretend the string is already cleaned. How would you check a plain string is a palindrome?
The first character must equal the last, the second must equal the second-to-last, and so on. You can compare from both ends at once instead of building a reversed copy.
Put left at index 0 and right at the last index. Move each one past characters that are not letters or digits, compare the two characters in lowercase, then step both inward until they meet.

Key idea

A palindrome is symmetric: the k-th character from the front equals the k-th character from the back. So you never need the reversed string. Put one pointer at each end and walk them toward each other, comparing as you go. The first mismatch proves the answer is False; if the pointers meet without a mismatch, it is True.

The clean-up rules fold into the same walk. A pointer that lands on a space or punctuation mark skips over it, and each comparison lowercases both characters. Nothing is copied, so the check takes O(n) time and O(1) extra space.

Approaches from the obvious one to the one you want in an interview

Do exactly what the statement says. Build the cleaned string (lowercase letters and digits only), build its reverse with [::-1], and compare the two.

This is already O(n) time, so for this Easy problem it is an acceptable answer. What it wastes is memory: it stores two new strings of up to n characters. Interviewers usually follow up with "can you do it in O(1) extra space?", which is the two-pointer version.

Dry run

  1. s = "race a car" → cleaned "raceacar"
  2. reversed → "racaecar"
  3. compare: r=r, a=a, c=c, then e vs a → different → False

Python

class Solution:
    def isPalindrome(self, s: str) -> bool:
        cleaned = "".join(c.lower() for c in s if c.isalnum())   # letters and digits, lowercased
        return cleaned == cleaned[::-1]                          # equal to its own reverse?
Time O(n)Space O(n)

One pass to clean, one to reverse, one to compare; the two new strings take O(n) memory.

When to use: Quick to write and hard to get wrong; fine unless O(1) extra space is required.

Watch it run

Compare the original string from both ends without cleaning it first.

  1. left = 0, right = len(s) - 1.
  2. Move left forward past characters that are not letters or digits, and right backward the same way.
  3. If s[left].lower() != s[right].lower(), return False.
  4. Otherwise step both inward and repeat while left < right.

Every skip loop is guarded by left < right, so a string made only of punctuation stops safely, and when the pointers meet on a middle character there is nothing left to compare. Each character is visited at most once.

Dry run

  1. s = "race a car": L=0 r, R=9 r → match
  2. L=1 a, R=8 a → match; L=2 c, R=7 c → match
  3. L=3 e; R=6 is a space → skip to R=5 a
  4. e != a → return False

Python

class Solution:
    def isPalindrome(self, s: str) -> bool:
        left, right = 0, len(s) - 1
        while left < right:
            while left < right and not s[left].isalnum():    # skip spaces/punctuation on the left
                left += 1
            while left < right and not s[right].isalnum():   # ... and on the right
                right -= 1
            if s[left].lower() != s[right].lower():
                return False                                 # one mismatched pair settles it
            left += 1
            right -= 1
        return True                                          # pointers met: every pair matched
Time O(n)Space O(1)

The pointers only move inward and together cross the string once; only two integers are stored.

When to use: The interview answer: same speed as the simple version, constant extra memory.

Common mistakes

  • Using str.isalpha() instead of str.isalnum(). Digits count: "0P" must be False ('0' vs 'p'), but dropping digits leaves "p" and wrongly returns True.
  • Writing the skip loops without the left < right guard. On a string of only punctuation such as ".,", the pointer runs off the end and raises IndexError.
  • Comparing before lowercasing: 'A' != 'a'. Lowercase both sides of every comparison.
  • Building the cleaned string with += in a loop: each += may copy the whole string, which is not guaranteed to be linear. Collect the characters and ''.join them once.

Python notes

  • c.isalnum() is True for letters and digits. c.lower() leaves digits and punctuation unchanged, so it is safe to call on any character.
  • s[::-1] builds a reversed copy in O(n) time and O(n) memory: fine for the simple version, avoided by the two-pointer one.
  • "".join(c.lower() for c in s if c.isalnum()) is the idiomatic way to write the clean-up step.
