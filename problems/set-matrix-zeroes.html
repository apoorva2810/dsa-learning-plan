Set Matrix Zeroes Medium

LeetCode #73 ↗
Status

Whenever a grid cell is 0, turn its whole row and column into zeros, changing the grid in place.

Problem

You are given an m × n grid of integers matrix. Whenever a cell holds 0, set every cell in its row and in its column to 0.

Do it in place: modify matrix itself and return nothing. Only the zeros that were in the grid originally count; zeros you write while working must not spread any further.

Examples

Example 1
Input: matrix = [[1,1,1],[1,0,1],[1,1,1]]
Output: [[1,0,1],[0,0,0],[1,0,1]]
The single 0 at row 1, column 1 clears row 1 and column 1.
Example 2
Input: matrix = [[0,1,2,0],[3,4,5,2],[1,3,1,5]]
Output: [[0,0,0,0],[0,4,5,0],[0,3,1,0]]
The zeros sit in columns 0 and 3, so those two columns are cleared (and row 0 as well).
Example 3
Input: matrix = [[1,2,3]]
Output: [[1,2,3]]
No zero, nothing changes.

Constraints

  • m == matrix.length
  • n == matrix[0].length
  • 1 <= m, n <= 200
  • -2^31 <= matrix[i][j] <= 2^31 - 1

Key idea

The trap is the order of events. If you clear a row and column as soon as you find a 0, the zeros you just wrote look exactly like original zeros, so the clearing keeps spreading and can wipe the whole grid. The fix is to separate finding from clearing: first scan the grid and write down which rows and which columns contain a 0; only then clear them.

"Write down" can be two sets, zero_rows and zero_cols: O(m + n) memory. To get that down to O(1), look for free memory inside the grid. A row that will be cleared is going to be all zeros anyway, so its first cell, matrix[r][0], can carry the note "clear row r" at no cost: that cell becomes 0 regardless. In the same way matrix[0][c] can carry "clear column c". The first row and the first column become the two sets.

Two details make it work. (1) The first row and column have zeros of their own that must not be confused with notes, so remember them in two booleans, first_row_zero and first_col_zero, before the cells are used as notes. (2) Process the inside of the grid (rows and columns from 1) first, reading the notes, and clear the first row and first column last; otherwise you destroy the notes before you have read them.

Approaches from the obvious one to the one you want in an interview

Make a copy of the original grid. Scan the copy for zeros, and for each zero found, clear that row and that column in the real matrix. Because we only read zeros from the untouched copy, the zeros we write into matrix can never spread.

It is correct and easy to reason about. The costs: a full copy (O(m · n) memory), and every zero clears a whole row and column, so with many zeros the work grows to about O(m · n · (m + n)).

Dry run

  1. matrix = [[1,0],[1,1]]; the copy is [[1,0],[1,1]].
  2. The copy has a zero at (0,1): clear row 0 and column 1 of matrix → [[0,0],[1,0]].
  3. No other zero in the copy → done. (Scanning matrix itself would have found the new zero at (0,0) and cleared column 0 too, which is wrong.)

Python

class Solution:
    def setZeroes(self, matrix: List[List[int]]) -> None:
        rows, cols = len(matrix), len(matrix[0])
        original = [row[:] for row in matrix]        # a real copy: its rows are new lists
        for r in range(rows):
            for c in range(cols):
                if original[r][c] == 0:              # only ORIGINAL zeros count
                    for i in range(rows):
                        matrix[i][c] = 0             # clear the column
                    for j in range(cols):
                        matrix[r][j] = 0             # clear the row
Time O(m · n · (m + n))Space O(m · n)

Each of up to m · n zeros clears a row and a column (m + n cells). The copy holds m · n values.

When to use: To get a correct answer first. The copy is what makes it safe, and also what we try to remove next.

Separate finding from clearing. Pass 1: scan the grid and put the row number and the column number of every zero into two sets, zero_rows and zero_cols. Pass 2: set a cell to 0 whenever its row is in zero_rows or its column is in zero_cols.

Each cell is looked at twice, so the time is O(m · n). The sets hold at most m + n numbers, so the extra memory is O(m + n), far less than a copy of the grid. This is the answer most people give first, and it is a perfectly good one.

Dry run

  1. matrix = [[0,1,2,0],[3,4,5,2],[1,3,1,5]]
  2. Pass 1: zeros at (0,0) and (0,3) → zero_rows = {0}, zero_cols = {0, 3}.
  3. Pass 2: row 0 is in zero_rows → the whole row becomes 0. Columns 0 and 3 are in zero_cols → matrix[1][0], matrix[2][0], matrix[1][3], matrix[2][3] become 0.
  4. Result [[0,0,0,0],[0,4,5,0],[0,3,1,0]].

Python

class Solution:
    def setZeroes(self, matrix: List[List[int]]) -> None:
        rows, cols = len(matrix), len(matrix[0])
        zero_rows, zero_cols = set(), set()
        for r in range(rows):                        # pass 1: only look, change nothing
            for c in range(cols):
                if matrix[r][c] == 0:
                    zero_rows.add(r)
                    zero_cols.add(c)
        for r in range(rows):                        # pass 2: clear
            for c in range(cols):
                if r in zero_rows or c in zero_cols:
                    matrix[r][c] = 0
Time O(m · n)Space O(m + n)

Two full scans; the sets hold at most m + n numbers.

When to use: The sensible default. Move to the constant-space version only if the interviewer asks for it.

Watch it run

Reuse the grid as the two sets. A 0 in matrix[r][0] means "clear row r"; a 0 in matrix[0][c] means "clear column c". Writing a note there costs nothing, because those cells belong to a row or column that is going to be cleared anyway.

  1. Before touching anything, remember whether the first row and the first column contain a zero (two booleans).
  2. Scan the inner cells (row ≥ 1, column ≥ 1). For each zero, write the notes matrix[r][0] = 0 and matrix[0][c] = 0.
  3. Clear every inner cell whose row note or column note is 0.
  4. Last, clear the first row if first_row_zero, and the first column if first_col_zero.

The order matters: the inner pass must read the notes before the first row and column are cleared. Time O(m · n), extra space O(1).

Dry run

  1. matrix = [[1,1,1],[1,0,1],[1,1,1]]: first_row_zero = False, first_col_zero = False.
  2. Pass 1: the inner cell (1,1) is 0 → notes matrix[1][0] = 0 and matrix[0][1] = 0 → [[1,0,1],[0,0,1],[1,1,1]].
  3. Pass 2: (1,2): row note matrix[1][0] is 0 → clear. (2,1): column note matrix[0][1] is 0 → clear. (2,2): no note → stays 1.
  4. Pass 3: both booleans are False, so the first row and column keep their values (their zeros are the notes, which are correct). Result [[1,0,1],[0,0,0],[1,0,1]].

Python

class Solution:
    def setZeroes(self, matrix: List[List[int]]) -> None:
        rows, cols = len(matrix), len(matrix[0])
        first_row_zero = 0 in matrix[0]                            # remember the first row's own zeros ...
        first_col_zero = any(matrix[r][0] == 0 for r in range(rows))   # ... and the first column's
        for r in range(1, rows):                                   # pass 1: write notes for inner zeros
            for c in range(1, cols):
                if matrix[r][c] == 0:
                    matrix[r][0] = 0                               # note: "clear row r"
                    matrix[0][c] = 0                               # note: "clear column c"
        for r in range(1, rows):                                   # pass 2: clear inner cells that have a note
            for c in range(1, cols):
                if matrix[r][0] == 0 or matrix[0][c] == 0:
                    matrix[r][c] = 0
        if first_row_zero:                                         # pass 3: the notebook pages go last
            for c in range(cols):
                matrix[0][c] = 0
        if first_col_zero:
            for r in range(rows):
                matrix[r][0] = 0
Time O(m · n)Space O(1)

At most three scans of the grid. The only extra memory is two booleans.

When to use: When constant extra space is required. Be ready to explain why the first row and column are handled last.

Common mistakes

  • Clearing a row and column as soon as a 0 is found. The new zeros are indistinguishable from original ones: on [[1, 0], [1, 1]] the zero written at (0, 0) would wrongly clear column 0 as well.
  • Forgetting the two booleans in the constant-space version. Without them you cannot tell whether the first row (or column) held a zero originally or only holds a note, so you clear it when you should not, or leave it alone when you should clear it.
  • Clearing the first row and column before the inner cells. Those cells hold the notes the inner pass still has to read. Do the inner cells first and the first row and column last.
  • Making a "copy" with copy = matrix or matrix[:]. The first is the same list; the second copies only the outer list, so the rows are still shared and writing into the copy changes the original. Use [row[:] for row in matrix].
  • A grid with one row or one column. The inner loops (from index 1) do nothing, so everything depends on the two booleans. Test [[1, 0, 3]] and [[1], [0], [3]].

Python notes

  • 0 in matrix[0] tests the first row for a zero in one expression. For the first column use any(row[0] == 0 for row in matrix).
  • matrix[r][:] = [0] * n overwrites a whole row in place (the row stays the same list object). matrix[r] = [0] * n also works here because it replaces the row inside the caller's outer list; but matrix = [...] would not, because it only rebinds the local name.
  • [row[:] for row in matrix] is a copy of the grid with its own rows. matrix.copy() and matrix[:] copy only the outer list, so the rows would still be shared.
  • A set of row numbers answers "is row r marked?" in O(1).

Follow-up questions

What an interviewer might ask next, and what changes.

  • Game of Life LC 289 — another in-place update where every new value depends on old values; the trick is to encode old and new state together in one cell, much like the notes here.
  • Valid Sudoku LC 36 — the same bookkeeping of "which rows and columns already contain X" with sets, extended to 3 × 3 boxes.
  • 01 Matrix LC 542 — instead of clearing the row and column, give every cell its distance to the nearest 0: start a BFS from all the zeros at once.
  • What if the grid does not fit in memory? — the O(1) trick needs random access to write notes. Stream instead: one pass over the rows to collect the two sets (O(m + n) memory), then a second pass that writes each row out cleared.
  • What if the grid is huge but has very few zeros? — store only the coordinates of the zeros: the sets of rows and columns come straight from them, and you clear only the marked rows and columns instead of scanning every cell twice.
