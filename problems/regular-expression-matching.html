Regular Expression Matching Hard

LeetCode #10 ↗
Status

Decide whether a pattern with . and * matches an entire string.

Problem

Given a string s and a pattern p, decide whether p matches all of s. The pattern can contain two special characters:

  • . matches any single character.
  • * matches zero or more copies of the element right before it. That element is a letter or a ., so a* means "any number of as, including none" and .* means "any run of any characters".

Matching the whole string is required: a pattern that matches only the beginning of s does not count. Return True if the pattern matches and False otherwise. Every * in the pattern has a letter or . in front of it.

Examples

Example 1
Input: s = "aa", p = "a"
Output: false
The pattern a matches one a, but the string has two. Matching only part of s is not enough.
Example 2
Input: s = "ab", p = ".*"
Output: true
.* is 'any number of any character', so it covers ab.
Example 3
Input: s = "aab", p = "c*a*b"
Output: true
c* matches zero cs, a* matches the two as, and b matches b.

Constraints

  • 0 <= len(s) <= 20 (the original problem promises at least 1 character; an empty string works here too)
  • 1 <= len(p) <= 20
  • s contains only lowercase letters
  • p contains only lowercase letters, '.' and '*'
  • every '*' has a letter or '.' directly before it

Think first try before reading the solution

Compare from the end. If the last pattern character is a letter or ., it has to match the last character of s, and everything before must match too. What changes when the last pattern character is *?
A starred element x* gives two choices that cover every case: use it zero times (throw away x* and compare the same string with the shorter pattern), or let it absorb one more character (x must match the last character of s; drop that character but keep x* in the pattern so it can absorb more).
State: dp[i][j] = does s[:i] match p[:j] completely? Fill an (m + 1) × (n + 1) table. Row 0 is not all False: a*b* matches the empty string, so dp[0][j] = dp[0][j - 2] whenever p[j - 1] is *.

Key idea

Define dp[i][j] as True when the first i characters of s are matched exactly by the first j characters of p: nothing left over on either side. Look at the last pattern character, p[j - 1].

  • A letter or .. It stands for exactly one character, so it must match s[i - 1] (equal letters, or the pattern has .), and everything before it must match: dp[i][j] = dp[i - 1][j - 1]. The string needs at least one character, so i = 0 gives False.
  • A *. It belongs to the element x = p[j - 2] in front of it, and x* is one unit that can repeat any number of times. Two cases cover every number of copies, so there is no need to know how many were used:
    • Zero copies: x* matches nothing. Remove it from the pattern: dp[i][j - 2], two columns to the left.
    • One more copy: x matches the last string character (x == s[i - 1] or x is .). That character is used up, but the pattern keeps x* so it may absorb more: dp[i - 1][j], the cell directly above.

The cell is True if either case is True.

Base cases: dp[0][0] is True (empty matches empty), and dp[i][0] is False for i > 0. Row 0 needs its own pass, because a*b*c* can match the empty string: dp[0][j] = dp[0][j - 2] when p[j - 1] is *, and False otherwise. The answer is dp[m][n]: whole string against whole pattern.

Reading from the end mirrors Longest Common Subsequence and Edit Distance. The same recurrence can also be written on suffixes, reading the pattern left to right; the table is just the mirror image.

Approaches from the obvious one to the one you want in an interview

Let match(i, j) mean: do the first i characters of s match the first j characters of p exactly?

  • j == 0: the empty pattern matches only the empty string, so i == 0.
  • Last pattern character is *, with element x = p[j - 2]: it matches if match(i, j - 2) (zero copies, drop x*), or if i > 0, x matches s[i - 1], and match(i - 1, j) (one more copy; the star stays).
  • Otherwise (a letter or .): i > 0, it matches s[i - 1], and match(i - 1, j - 1).

Without a cache this explores the same (i, j) pairs along many routes. With 20 as as the string and the pattern b followed by nine a*, the uncached version makes about 24 million calls before answering False, because each a* can split the as in many ways and the mismatch on b is only found at the very end. With @cache there are at most (m + 1)(n + 1) = 420 different calls, each doing O(1) work.

Dry run

  1. s = "aa", p = "a*": match(2, 2). The last pattern element is a*.
  2. Zero copies: match(2, 0). The pattern is empty but the string is not → False.
  3. One more copy: a matches the last a of s → match(1, 2), same pattern, shorter string.
  4. match(1, 2): zero copies → match(1, 0) False; one more copy → match(0, 2).
  5. match(0, 2): zero copies → match(0, 0) → True. So match(1, 2) and match(2, 2) are True.

Python

class Solution:
    def isMatch(self, s: str, p: str) -> bool:
        @cache                                           # one stored answer per pair (i, j)
        def match(i: int, j: int) -> bool:
            """Do the first i characters of s match the first j characters of p, exactly?"""
            if j == 0:                                   # empty pattern: only the empty string matches
                return i == 0
            if p[j - 1] == "*":                          # last element is x*, with x = p[j - 2]
                if match(i, j - 2):                      # zero copies: drop x* from the pattern
                    return True
                # one more copy: x must match the last character of s; keep x* for further characters
                return i > 0 and p[j - 2] in (s[i - 1], ".") and match(i - 1, j)
            # a letter or a dot: it must match the last character of s, then both shrink by one
            return i > 0 and p[j - 1] in (s[i - 1], ".") and match(i - 1, j - 1)

        return match(len(s), len(p))
Time O(m·n)Space O(m·n)

(m + 1)(n + 1) states with O(1) work each. The recursion is at most m + n frames deep.

When to use: The quickest correct version to write once the two cases for * are clear. Delete @cache and you see the exponential blow-up first-hand.

Store the same answers in an (m + 1) × (n + 1) table, filled so that every cell finds its inputs ready. Row 0 and column 0 are the empty prefix.

  • dp[0][0] = True, and the rest of column 0 is False.
  • Row 0: dp[0][j] = dp[0][j - 2] when p[j - 1] is * (the starred element vanishes), otherwise False.
  • Every other cell, row by row and left to right:
    • p[j - 1] is a letter or .: dp[i][j] = dp[i - 1][j - 1] if it matches s[i - 1], otherwise False.
    • p[j - 1] is * with x = p[j - 2]: dp[i][j] = dp[i][j - 2] (zero copies) or, if x matches s[i - 1], dp[i - 1][j] (one more copy).

The cells it reads are always to the left or above, so a row-by-row fill is safe. The answer is dp[m][n]. The table also lets you walk back through the True cells to see which part of s each pattern element matched.

Dry run

  1. s = "aab", p = "c*a*b". Row 0 (empty string): [True, False, True, False, True, False], because c* and a* can each vanish.
  2. Row a: [False, False, False, True, True, False]. The letter a matches (zero cs, then a), and a* can hold that one a.
  3. Row a again: [False, False, False, False, True, False]. Only c*a* covers aa, with a* absorbing both: dp[2][4] = dp[1][4].
  4. Row b: [False, False, False, False, False, True]. The last pattern letter b matches the last b, and the diagonal dp[2][4] is True. The answer is dp[3][5] = True.

Python

class Solution:
    def isMatch(self, s: str, p: str) -> bool:
        m, n = len(s), len(p)
        dp = [[False] * (n + 1) for _ in range(m + 1)]   # dp[i][j]: s[:i] matches p[:j] exactly
        dp[0][0] = True                                  # empty string, empty pattern
        for j in range(2, n + 1):                        # row 0: a starred element may vanish, so a*b* matches ""
            if p[j - 1] == "*":
                dp[0][j] = dp[0][j - 2]
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                if p[j - 1] == "*":                      # last element is x*, with x = p[j - 2]
                    zero = dp[i][j - 2]                  # zero copies: drop x*
                    more = p[j - 2] in (s[i - 1], ".") and dp[i - 1][j]   # x absorbs s[i - 1], x* stays
                    dp[i][j] = zero or more
                else:                                    # a letter or a dot: one-to-one with s[i - 1]
                    dp[i][j] = p[j - 1] in (s[i - 1], ".") and dp[i - 1][j - 1]
        return dp[m][n]
Time O(m·n)Space O(m·n)

One O(1) update per cell of the (m + 1) × (n + 1) table.

When to use: The interview answer: no recursion, and the table shows exactly where a False comes from. Each row reads only itself and the row above, so two rows would be enough if memory mattered.

Watch it run

Look at which cells a cell reads: dp[i][j - 2] (same row, to the left), dp[i - 1][j] and dp[i - 1][j - 1] (the row above). Row i never needs a row older than i - 1, so two lists are enough: prev for row i - 1 and cur for row i. After finishing a row, prev = cur.

Memory falls from O(m·n) to O(n). With patterns of at most 20 characters it hardly matters, but the pattern is the same as for Longest Common Subsequence: a table that reads only the row above can be rolled. The trade-off is the same too: the walk back through the table (to see which part of s each element matched) is no longer possible.

Dry run

  1. s = "aa", p = "a*": prev starts as row 0 for the empty string: [True, False, True] (a* can vanish).
  2. i = 1 (a): cur[0] = False; j = 1 (a) → prev[0] = True → True; j = 2 (*) → zero copies cur[0] False, or a matches and prev[2] True → True. cur = [False, True, True].
  3. i = 2 (a): cur[1] = prev[0] = False; j = 2 → prev[2] = True with a matching → True. The answer is prev[2] = True.

Python

class Solution:
    def isMatch(self, s: str, p: str) -> bool:
        n = len(p)
        prev = [False] * (n + 1)                         # row for the previous prefix of s; starts as row 0 (empty s)
        prev[0] = True
        for j in range(2, n + 1):
            if p[j - 1] == "*":                          # a starred element may vanish
                prev[j] = prev[j - 2]
        for i in range(1, len(s) + 1):
            cur = [False] * (n + 1)                      # cur[0] stays False: an empty pattern cannot match s[:i]
            for j in range(1, n + 1):
                if p[j - 1] == "*":
                    zero = cur[j - 2]                    # same row, two to the left
                    more = p[j - 2] in (s[i - 1], ".") and prev[j]       # row above, same column
                    cur[j] = zero or more
                else:
                    cur[j] = p[j - 1] in (s[i - 1], ".") and prev[j - 1]  # row above, one to the left
            prev = cur                                   # this row becomes the "row above" for the next character
        return prev[n]
Time O(m·n)Space O(n)

The same m·n cell updates as the full table, with two lists of n + 1 booleans.

When to use: When memory matters or to show you can see which cells a recurrence reads. Keep the full table if you want to print it or recover the match.

Common mistakes

  • Treating * like the shell wildcard that matches anything. Here it only repeats the element before it: a* never matches b, and the 'anything' pattern is .*.
  • Being greedy. a*a against aa is True, but only if a* takes one a and leaves the other for the final a. A matcher that lets a* swallow everything fails here, so both choices (zero copies, one more copy) must be tried. The DP does that without backtracking.
  • Setting all of row 0 to False. The empty string matches a*, a*b* and .*: when p[j - 1] is *, copy dp[0][j - 2].
  • After a star absorbs a character, moving diagonally to dp[i - 1][j - 1] like an ordinary letter. That drops the star and allows only a single copy. Stay in column j: dp[i - 1][j].
  • Accepting a partial match: "aa" against "a" must be False. The answer is the corner cell dp[m][n], never a cell in the last row or last column.

Python notes

  • p[j - 1] in (s[i - 1], ".") is a short way to write "the pattern character equals the string character, or is a dot".
  • The table holds booleans. ok and dp[i - 1][j - 1] evaluates to False or to the stored boolean, so every cell stays a plain True or False.
  • re.fullmatch(p, s) from the standard library gives the same answers for these patterns (the meaning of . and * is the same). It is handy for checking a solution against many random inputs, but it is not what the problem asks for.
  • @cache keys on the pair (i, j). The recursion is at most len(s) + len(p) frames deep, well inside Python's default limit.
  • Build the table with [[False] * (n + 1) for _ in range(m + 1)]. Writing [[False] * (n + 1)] * (m + 1) would make every row the same list.

Follow-up questions

What an interviewer might ask next, and what changes.

  • Wildcard Matching LC 44 — the pattern has ? (any one character) and a standalone * (any sequence, including empty). The star no longer needs the element before it: dp[i][j] = dp[i][j - 1] or dp[i - 1][j]. A greedy two-pointer version with O(1) memory also works.
  • Distinct Subsequences LC 115 — the same (prefix, prefix) table, but counting ways instead of answering yes or no: add the two options instead of or-ing them.
  • Interleaving String LC 97 — another yes/no table over two prefixes; each cell asks whether the next character of the target can come from the first or the second string.
  • Valid Parenthesis String LC 678 — a different *: it can stand for (, ) or nothing. A table works, and so does tracking the smallest and largest possible number of open brackets while scanning.
  • Support `+` and `?` as well — x+ is x followed by x*, and x? is zero or one copy. Add the matching transitions to the recurrence: for x+ a copy is required before the loop, and for x? the loop is replaced by a single optional step.
  • Patterns with groups and alternation, such as `(ab|c)*` — the table no longer fits. Convert the pattern to a state machine (an NFA) and simulate it on the string, which is how engines that avoid exponential backtracking work.
