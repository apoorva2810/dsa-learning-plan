Add Binary Easy 250

LeetCode #67 ↗
Status

Add two binary numbers given as strings of 0s and 1s and return the sum as a binary string.

Problem

You are given two strings a and b that hold binary numbers. Every character is "0" or "1", and neither string has leading zeros, except for the number zero itself, which is written "0".

Return the sum of the two numbers as a binary string in the same format.

Examples

Example 1
Input: a = "101", b = "110"
Output: "1011"
5 + 6 = 11, which is 1011 in binary.
Example 2
Input: a = "1111", b = "1"
Output: "10000"
15 + 1 = 16. The carry runs through all four columns and creates a new leading digit.
Example 3
Input: a = "0", b = "0"
Output: "0"
Zero plus zero is "0", not an empty string.

Constraints

  • 1 <= len(a), len(b) <= 10^4
  • a and b contain only the characters 0 and 1
  • no leading zeros, except for the number 0 itself

Key idea

Binary addition is school addition with a smaller table. Work from the rightmost column to the left. In each column you add up to three digits: one from a, one from b, and the carry that the previous column passed on. The total can only be 0, 1, 2 or 3:

  • total 0 or 1: write the total, carry 0;
  • total 2 or 3: write total - 2 (that is 0 or 1) and carry 1.

In one line: digit = total % 2, carry = total // 2.

Put one pointer, i, on the last character of a and another, j, on the last character of b, and walk both to the left. A pointer that has fallen off the left end contributes 0, as if the shorter number had invisible zeros in front of it. Stop only when both pointers are off the end and the carry is 0, so a carry that outlives both strings still gets a column of its own (1 + 1 = 10). The digits appear from the lowest column to the highest, so reverse them once at the end.

Every column is visited once: O(n) time for the longer string of length n. The answer itself has about n digits, so O(n) space cannot be avoided.

Approaches from the obvious one to the one you want in an interview

Read each string as a base-2 number with int(s, 2), add the two integers, and turn the sum back into text with bin(...). bin puts a 0b in front, so slice off the first two characters.

In Python this is correct and even linear: integers have no size limit, and converting a power-of-two base walks the digits once. It counts as the brute answer because it skips the algorithm the problem is about. In Java or C++ the strings (up to 10,000 digits) overflow every built-in integer type, so an interviewer will usually ask you for the column addition instead.

Dry run

  1. a = "101", b = "110"
  2. int("101", 2) is 5 and int("110", 2) is 6
  3. 5 + 6 = 11
  4. bin(11) is '0b1011'; dropping the first two characters gives "1011"

Python

class Solution:
    def addBinary(self, a: str, b: str) -> str:
        total = int(a, 2) + int(b, 2)        # read both strings as base-2 numbers and add them
        return bin(total)[2:]                # bin(11) == '0b1011'; [2:] drops the '0b'
Time O(n)Space O(n)

n is the length of the longer string. Converting a base-2 string, adding and converting back each take one pass.

When to use: Scripts, or a quick way to check your answer. In an interview, mention it and then write the column loop.

Do what you do on paper. Put a pointer i on the last character of a, a pointer j on the last character of b, and keep a carry that is 0 or 1. Each round adds up to three numbers: the digit under i, the digit under j and the carry. A pointer that has fallen off the left end contributes 0.

The column total is 0, 1, 2 or 3. Write total % 2 and carry total // 2: a total of 2 writes 0 and carries 1, a total of 3 writes 1 and carries 1.

Keep going while a pointer is still on a digit or a carry is waiting, so the final carry gets a column of its own. The digits appear from the lowest column to the highest, so collect them in a list and reverse it once at the end.

Dry run

  1. a = "101", b = "110", i = j = 2, carry = 0
  2. column 0: 1 + 0 + 0 = 1, write 1, carry 0
  3. column 1: 0 + 1 + 0 = 1, write 1, carry 0
  4. column 2: 1 + 1 + 0 = 2, write 0, carry 1
  5. both strings used up, carry 1: 0 + 0 + 1 = 1, write 1, carry 0
  6. digits 1, 1, 0, 1 reversed: "1011"

Python

class Solution:
    def addBinary(self, a: str, b: str) -> str:
        i, j = len(a) - 1, len(b) - 1        # start on the last (lowest) digit of each string
        carry = 0
        digits = []                          # result digits, lowest column first
        while i >= 0 or j >= 0 or carry:     # a waiting carry still needs its own column
            total = carry
            if i >= 0:                       # a used-up string adds 0
                total += int(a[i])
                i -= 1
            if j >= 0:
                total += int(b[j])
                j -= 1
            digits.append(str(total % 2))    # the digit to write in this column
            carry = total // 2               # 1 when the column total is 2 or 3
        return "".join(reversed(digits))     # the lowest column was written first
Time O(n)Space O(n)

n is the length of the longer string. One round per column, plus at most one extra round for the final carry.

When to use: The interview answer. Say out loud why the loop condition ends with or carry, and why the digits are reversed.

Watch it run

Convert both strings to integers once and borrow the trick from Sum of Two Integers. x ^ y adds every column ignoring carries, and (x & y) << 1 finds the columns that carry and moves each carry one column to the left. Replace x by the XOR and y by the carries, and repeat until y is 0. For non-negative integers this always ends, because the lowest carry bit moves left in every round.

A long carry chain makes it slow. "111...1" + "1" needs one round per digit, and every round works on the whole number, so the worst case is quadratic. It is still fast for 10,000 digits, but the column loop is simpler to reason about and never worse than linear.

Dry run

  1. x = 5 (101), y = 6 (110)
  2. round 1: x ^ y = 011 (3), carries (101 & 110) << 1 = 1000 (8)
  3. round 2: x ^ y = 1011 (11), carries (011 & 1000) << 1 = 0
  4. y is 0, so x = 11 is the sum: bin(11)[2:] is "1011"

Python

class Solution:
    def addBinary(self, a: str, b: str) -> str:
        x, y = int(a, 2), int(b, 2)
        while y:                             # y holds the carries still to be added
            x, y = x ^ y, (x & y) << 1       # columns without carries, carries moved one column left
        return bin(x)[2:]
Time O(n²)Space O(n)

Worst case: a carry chain of n columns means n rounds, each on an n-bit number. Typical inputs finish in a handful of rounds.

When to use: To show you know the bit trick. For this problem the column loop is the better answer.

Common mistakes

  • Dropping the last carry. "1" + "1" is "10": after both pointers fall off the left end, a carry of 1 is still waiting. Put or carry in the loop condition.
  • Reading a string that has run out. In Python b[-1] does not raise an error, it silently returns the last character, so when j reaches -1 you would read a digit again. Test j >= 0 before every b[j].
  • Adding characters instead of numbers. a[i] + b[j] joins two strings ("1" + "1" is "11"). Convert each digit with int(...) first.
  • Building the answer with result = str(digit) + result. Each prepend copies the whole string, which makes the loop O(n²). Append to a list and reverse it once at the end.
  • Scanning from the left. Carries travel from the low columns to the high ones, and the two strings may have different lengths, so their left ends do not line up. Start at the right end of both.

Python notes

  • int(s, 2) reads a string as a base-2 number and bin(n) writes one, with a 0b prefix: bin(11) is '0b1011'. Use bin(n)[2:] or format(n, "b") to drop the prefix.
  • Python integers have no size limit, so int(a, 2) works for 10,000 digits. Recent Python versions (3.12 here) refuse to convert more than 4,300 decimal digits by default, but that limit does not apply to base 2, which is a power of two.
  • carry, digit = divmod(total, 2) computes total // 2 and total % 2 in one call.
  • "".join(reversed(digits)) and "".join(digits[::-1]) both reverse a list of single characters into a string.

Follow-up questions

What an interviewer might ask next, and what changes.

  • Sum of Two Integers LC 371 — the same carry logic on whole integers: XOR adds the columns without carries, and AND shifted left finds the carries, repeated until none are left.
  • Add Strings LC 415 — the same loop in base 10. Replace % 2 and // 2 with % 10 and // 10; a column total is at most 9 + 9 + 1 = 19, so the carry is still 0 or 1.
  • Add Two Numbers LC 2 — the same carry loop over two linked lists whose digits are stored lowest digit first, so you can walk them in the order the carry travels.
  • Add Two Numbers II LC 445 — the lists store the highest digit first, so you cannot start at the low end: push the digits on two stacks (or reverse the lists) and pop them.
  • Plus One LC 66 — adding the constant 1 to a list of digits: the carry only survives through a run of 9s at the right end.
  • Multiply Strings LC 43 — schoolbook multiplication: add every digit product into its column first, then sweep once from the right carrying everything above 9.
