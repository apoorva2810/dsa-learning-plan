Verifying An Alien Dictionary Easy 250

LeetCode #953 ↗
Status

Check whether a list of words is sorted according to a custom alphabet order.

Problem

An alien language uses the 26 lowercase English letters, but in a different order. The string order lists the 26 letters from first to last in that alphabet.

You are given a list words. Return True if the words are sorted lexicographically in the alien alphabet and False otherwise. Lexicographic order works like a dictionary: compare two words position by position from the left; the first position where the letters differ decides, using their positions in order. If no position differs (one word is a prefix of the other), the shorter word comes first.

Examples

Example 1
Input: words = ["hello","leetcode"], order = "hlabcdefgijkmnopqrstuvwxyz"
Output: true
The words differ at position 0: 'h' comes before 'l' in this alphabet, so 'hello' belongs first.
Example 2
Input: words = ["word","world","row"], order = "worldabcefghijkmnpqstuvxyz"
Output: false
'word' and 'world' first differ at position 3: 'd' versus 'l'. In this alphabet 'l' comes before 'd', so 'world' should be first.
Example 3
Input: words = ["apple","app"], order = "abcdefghijklmnopqrstuvwxyz"
Output: false
'app' is a prefix of 'apple', so the shorter word 'app' must come first.

Constraints

  • 1 <= len(words) <= 100
  • 1 <= len(words[i]) <= 20
  • len(order) == 26
  • all letters are lowercase English letters; order contains each of them exactly once

Think first try before reading the solution

A list is sorted exactly when every word is in order with the next word. You never have to compare words that are not neighbours.
To compare two words, walk both from the left. The first position where the letters differ decides, by where those letters sit in order. A dictionary from letter to position makes that lookup O(1).
If you walk off the end of one word without finding a difference, the shorter word must come first: 'app' before 'apple'. Compare the lengths.

Key idea

Sortedness is a local property: if each word is in order with the word right after it, the whole list is sorted, because "comes before" carries over along the chain. So the job shrinks to checking the n − 1 adjacent pairs.

Comparing two words in an alien alphabet is exactly what a dictionary does with a different alphabet. Walk both words from the left; the first position where they disagree decides, and all later letters are irrelevant. "Which letter comes first?" is answered by the letter's position in order, so build a rank dictionary once (rank["h"] = 0, rank["l"] = 1, ...). One special case remains: when the two words agree on every position of the shorter one, the shorter word goes first. Every letter is looked at a constant number of times, so the time is O(L) for L total letters.

This is the easy half of Alien Dictionary (LeetCode 269), where you are given the sorted words and must recover the order. There, the same adjacent-pair comparison produces "this letter comes before that one" edges, and a topological sort turns the edges into an alphabet. That is why this warm-up lives with the graph problems.

Approaches from the obvious one to the one you want in an interview

Rename the letters so that the alien alphabet becomes the English one: the first letter of order becomes a, the second b, and so on. After translating every word, the question "is the list sorted in the alien alphabet?" turns into "is the translated list sorted in the ordinary alphabet?", which sorted() answers.

It works, but it does more than necessary: sorting makes O(n log n) word comparisons when only n − 1 are needed, and it builds a translated copy of every word.

Dry run

  1. Example 2: order = "worldabc..." maps w → a, o → b, r → c, l → d, d → e.
  2. "word" → "abce", "world" → "abcde", "row" → "cba".
  3. sorted(["abce", "abcde", "cba"]) = ["abcde", "abce", "cba"], which differs from the translated list → False.

Python

class Solution:
    def isAlienSorted(self, words: List[str], order: str) -> bool:
        # the i-th alien letter becomes the i-th English letter
        to_english = {ch: chr(ord("a") + i) for i, ch in enumerate(order)}
        translated = ["".join(to_english[ch] for ch in word) for word in words]
        return translated == sorted(translated)       # now the ordinary alphabet applies
Time O(L + n log n · m)Space O(L)

L is the total number of letters, n the number of words and m the longest word: translating costs O(L), sorting makes O(n log n) comparisons of up to m letters each.

When to use: Only to see the idea. The sort is wasted work when a single pass over adjacent pairs is enough.

Store each letter's position in order in a dictionary rank. Then compare every word with the next one: walk both from the left, and at the first position where they differ, the word whose letter has the smaller rank must be the first one. If the walk reaches the end of a word without a difference, the shorter word must be first. The moment a pair is out of order, return False; if all pairs pass, return True.

Each pair's comparison stops at the first difference and never looks at the rest, so no letter is read more than a constant number of times: O(L) time, with only the 26-entry map as extra space.

Dry run

  1. Example 2: rank = {w: 0, o: 1, r: 2, l: 3, d: 4, ...}.
  2. Pair "word" / "world": positions 0, 1, 2 agree (w, o, r). Position 3: "d" (rank 4) vs "l" (rank 3).
  3. "l" comes first, so "world" should be before "word" → return False without looking at "row".
  4. Example 3: "apple" / "app": all 3 shared positions agree; len 5 > len 3, so the longer word is first → False.

Python

class Solution:
    def isAlienSorted(self, words: List[str], order: str) -> bool:
        rank = {ch: i for i, ch in enumerate(order)}      # letter -> position in the alien alphabet

        def in_order(w1: str, w2: str) -> bool:
            for c1, c2 in zip(w1, w2):                    # walk both words from the left
                if c1 != c2:
                    return rank[c1] < rank[c2]            # the first difference decides
            return len(w1) <= len(w2)                     # no difference: the shorter word must come first

        for i in range(len(words) - 1):
            if not in_order(words[i], words[i + 1]):      # one bad neighbouring pair breaks the order
                return False
        return True
Time O(L)Space O(1)

Each adjacent comparison reads letters until the first difference; summed over all pairs that is at most the total number of letters L. The rank map has 26 entries.

When to use: The default answer, and the comparison you will reuse in Alien Dictionary.

Watch it run

Turn every word into its list of ranks, for example "hello" → [0, 6, 1, 1, 15] in example 1. Python compares two lists lexicographically: element by element, first difference decides, and a list that runs out first is smaller. That is exactly the alien dictionary rule, including the prefix case, so key(w1) <= key(w2) is the whole comparison.

Same O(L) time, a little more memory (the two rank lists of each pair), and much shorter code. The trade-off: the loop is hidden inside the <=, so make sure you can explain what it does.

Python

class Solution:
    def isAlienSorted(self, words: List[str], order: str) -> bool:
        rank = {ch: i for i, ch in enumerate(order)}

        def key(word: str) -> List[int]:
            return [rank[ch] for ch in word]              # the word as a list of alphabet positions

        # list comparison is lexicographic and treats a prefix as smaller: exactly the dictionary rule
        return all(key(words[i]) <= key(words[i + 1]) for i in range(len(words) - 1))
Time O(L)Space O(m)

Every letter is converted once per pair it takes part in (at most twice); m is the longest word.

When to use: When you want the shortest correct code and your reader knows how Python compares sequences.

Common mistakes

  • Forgetting the prefix rule. ["apple", "app"] must give False: the loop over shared positions finds no difference, and a solution that then returns True without comparing the lengths is wrong.
  • Stopping at the first pair that is in order. One good pair proves nothing; every adjacent pair must pass. Only the first bad pair lets you return early.
  • Comparing with Python's < on the raw words. That uses the English alphabet; in example 1, "hello" < "leetcode" happens to agree with the alien order, but example 2 would come out wrong.
  • Calling order.index(c) for every letter. It scans up to 26 characters each time; harmless here, but the habit costs you when the alphabet is large. Build the rank map once.
  • Comparing every pair of words instead of adjacent ones: O(n²) comparisons for no gain.

Python notes

  • rank = {ch: i for i, ch in enumerate(order)} builds the letter → position map in one line.
  • zip(w1, w2) walks the two words together and stops at the end of the shorter one, so the prefix rule is just a length check after the loop.
  • zip(words, words[1:]) yields the adjacent pairs; all(...) over a generator stops at the first pair that fails.
  • Python compares lists lexicographically with the prefix rule built in, so [rank[c] for c in w1] <= [rank[c] for c in w2] is a complete comparison. Handy, but know what it hides: it is the same loop.

Follow-up questions

What an interviewer might ask next, and what changes.

  • Alien Dictionary LC 269 — the reverse problem: the words are sorted and you must find order. Each adjacent pair's first difference gives one edge 'x before y'; a topological sort of those edges is the alphabet.
  • Custom Sort String LC 791 — rearrange one string so its letters follow a custom order: the same rank map, used as a sort key, or counting sort over the order string.
  • Compare Version Numbers LC 165 — the same left-to-right comparison, but over dot-separated numbers, and a missing chunk counts as 0 instead of 'shorter comes first'.
  • Longest Common Prefix LC 14 — the same walk over aligned positions, stopping at the first mismatch; here the position itself is the answer rather than who wins.
  • Return the first out-of-order pair instead of a boolean — return the index i of the first adjacent pair that fails (or -1). Nothing else changes.
  • Sort the words into the alien order — use the rank list as the key: sorted(words, key=lambda w: [rank[c] for c in w]). Python's list comparison already applies the prefix rule.
