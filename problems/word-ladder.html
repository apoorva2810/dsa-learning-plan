Word Ladder Hard

LeetCode #127 ↗
Status

Find the length of the shortest chain of one-letter edits that turns one word into another.

Problem

You are given two words, beginWord and endWord, and a dictionary wordList. A ladder is a sequence of words that starts with beginWord and ends with endWord, where

  • each word differs from the one before it in exactly one letter (same position, all words have the same length),
  • every word after beginWord must appear in wordList (beginWord itself does not have to).

Return the number of words in the shortest ladder, or 0 if no ladder exists.

Examples

Example 1
Input: beginWord = "hit", endWord = "cog", wordList = ["hot", "dot", "dog", "lot", "log", "cog"]
Output: 5
hit → hot → dot → dog → cog: five words (four letter changes).
Example 2
Input: beginWord = "hit", endWord = "cog", wordList = ["hot", "dot", "dog", "lot", "log"]
Output: 0
"cog" is not in the list, so no ladder can end there.
Example 3
Input: beginWord = "a", endWord = "c", wordList = ["a", "b", "c"]
Output: 2
a → c changes one letter directly.

Constraints

  • 1 <= len(beginWord) <= 10 and len(endWord) == len(beginWord)
  • 1 <= len(wordList) <= 5000, every word has the same length as beginWord
  • all words are lowercase English letters; the words in wordList are distinct
  • beginWord != endWord

Think first try before reading the solution

Think of every word as a node, with an edge between two words that differ in one letter. What is the question in graph terms?
It asks for the fewest steps in a graph where every step costs the same, which is exactly what BFS (breadth-first search) finds. The real work is finding a word's neighbours quickly.
Comparing a word with all N others costs O(N · L). Instead, file every word under its L wildcard patterns (hot → *ot, h*t, ho*). Two words are one letter apart exactly when they share a pattern.

Key idea

The words form an implicit graph: you are never handed the edges, but you can work out a word's neighbours (the words one letter away) on demand. The question asks for the shortest path from beginWord to endWord, and every edge costs one step, so BFS answers it: BFS visits words in rings (everything 1 change away, then 2, then 3), so the first time it reaches endWord it has used the fewest changes.

The bottleneck is neighbour lookup. Replace one letter with * and you get a pattern; hot, dot and lot all match *ot. Group the dictionary by pattern once (a dictionary from pattern to words). A word's neighbours are then the other words in its L buckets, with no scan of the whole list. After a bucket has been used once, every word in it is visited or queued, so it can be emptied: no later word could reach those words any sooner.

Approaches from the obvious one to the one you want in an interview

Run BFS from beginWord, storing (word, length) in the queue. To find the neighbours of the word you pop, walk the whole dictionary and keep every unvisited word that differs in exactly one position.

BFS guarantees the first arrival at endWord is the shortest ladder. The cost is neighbour discovery: each of up to N popped words compares itself with all N words at O(L) per comparison, O(N² · L) in total. With N = 5000 and L = 10 that is 250 million letter comparisons.

Dry run

  1. hit: scan all six words → only hot differs in one letter → queue [(hot, 2)]
  2. hot: scan again → dot, lot → queue [(dot, 3), (lot, 3)]
  3. dot → dog (4). lot → log (4). dog → cog = endWord → return 4 + 1 = 5

Python

class Solution:
    def ladderLength(self, beginWord: str, endWord: str, wordList: List[str]) -> int:
        def one_apart(a: str, b: str) -> bool:
            return sum(x != y for x, y in zip(a, b)) == 1

        if endWord not in wordList:
            return 0
        visited = {beginWord}
        queue = deque([(beginWord, 1)])            # (word, words in the ladder so far)
        while queue:
            word, length = queue.popleft()
            for nxt in wordList:                   # compare with EVERY word: O(N * L) per pop
                if nxt not in visited and one_apart(word, nxt):
                    if nxt == endWord:
                        return length + 1
                    visited.add(nxt)
                    queue.append((nxt, length + 1))
        return 0
Time O(N² · L)Space O(N)

Up to N pops, each comparing against N words letter by letter.

When to use: Only for tiny dictionaries; it is the version to improve on.

Flip the neighbour search around. Instead of asking every dictionary word "are you one letter away?", generate every word that is one letter away, by trying each of the 26 letters at each of the L positions, and keep the ones that are in the dictionary (a set, so each check is O(L) for hashing the string).

Each pop now costs 26 · L candidates of length L, independent of N: O(N · 26 · L²) overall. For large dictionaries that beats the quadratic scan, but most of the 26 · L candidates are not real words.

Dry run

  1. hit: try ait…zit, hat…hzt, hia…hiz → only hot is in the set → queue [(hot, 2)]
  2. hot → dot, lot (3) → dot → dog (4) → dog → cog = endWord → 5

Python

class Solution:
    def ladderLength(self, beginWord: str, endWord: str, wordList: List[str]) -> int:
        words = set(wordList)                      # O(1) average membership checks
        if endWord not in words:
            return 0
        visited = {beginWord}
        queue = deque([(beginWord, 1)])
        while queue:
            word, length = queue.popleft()
            for i in range(len(word)):
                for letter in string.ascii_lowercase:     # every one-letter change at position i
                    nxt = word[:i] + letter + word[i + 1:]
                    if nxt == endWord:
                        return length + 1
                    if nxt in words and nxt not in visited:
                        visited.add(nxt)
                        queue.append((nxt, length + 1))
        return 0
Time O(N · 26 · L²)Space O(N · L)

Each popped word builds 26 · L candidate strings of length L; the set holds all N words.

When to use: A fine answer that needs no preprocessing; it is often what people write first.

Preprocess the dictionary once: for every word and every position, replace that letter with * and append the word to buckets[pattern]. Two words differ in exactly one letter exactly when they share a pattern, so a popped word's neighbours are the words in its own L buckets.

Run BFS from beginWord with (word, length) pairs. For each popped word, scan its L buckets, return length + 1 the moment endWord shows up, and queue every unvisited word. Then empty the bucket: every word in it is now visited or queued at the current distance, so no later word could reach them any sooner. With that, every bucket is scanned once: O(N · L²) for building the patterns, and the same for the search.

Dry run

  1. wordList = ["hot", "dot", "dog", "lot", "log", "cog"] → *ot: [hot, dot, lot], do*: [dot, dog], *og: [dog, log, cog], lo*: [lot, log], h*t: [hot], …
  2. Pop hit (1): buckets *it, h*t, hi* → hot is new → queue [(hot, 2)]
  3. Pop hot (2): *ot → dot, lot are new → queue [(dot, 3), (lot, 3)]; bucket *ot emptied
  4. Pop dot (3): do* → dog (4). Pop lot (3): lo* → log (4)
  5. Pop dog (4): *og contains cog = endWord → return 4 + 1 = 5

Python

class Solution:
    def ladderLength(self, beginWord: str, endWord: str, wordList: List[str]) -> int:
        if endWord not in wordList:
            return 0
        L = len(beginWord)
        buckets = defaultdict(list)                # "h*t" -> every dictionary word matching it
        for word in wordList:
            for i in range(L):
                buckets[word[:i] + "*" + word[i + 1:]].append(word)
        visited = {beginWord}
        queue = deque([(beginWord, 1)])            # (word, words in the ladder so far)
        while queue:
            word, length = queue.popleft()
            for i in range(L):
                pattern = word[:i] + "*" + word[i + 1:]
                for nxt in buckets[pattern]:
                    if nxt == endWord:
                        return length + 1
                    if nxt not in visited:
                        visited.add(nxt)           # mark when queued, not when popped
                        queue.append((nxt, length + 1))
                buckets[pattern] = []              # all of these are queued: never scan this bucket again
        return 0
Time O(N · L²)Space O(N · L²)

N · L patterns, each built in O(L); every bucket is scanned at most once during the BFS.

When to use: The strongest single-direction answer. Mention bidirectional BFS as the next speed-up.

Common mistakes

  • Counting changes instead of words. hit → hot → dot → dog → cog has four changes but the answer is 5. Start beginWord at length 1.
  • Marking a word visited when it is popped instead of when it is queued. The same word then enters the queue many times and the search can blow up.
  • Searching with DFS. It finds a ladder, not the shortest; trying every path to find the shortest is exponential.
  • Checking word in wordList on the list itself: each check scans all N words. Convert to a set first.
  • In the 26-letter version, returning as soon as a generated word equals endWord without having checked that endWord is in the dictionary at all.

Python notes

  • word[:i] + "*" + word[i + 1:] builds the pattern with letter i blanked out. Strings are immutable, so this creates a new string of length L, which is where the extra factor of L in the complexity comes from.
  • defaultdict(list) lets you append to a bucket without checking whether it exists yet.
  • deque.popleft() is O(1); never use list.pop(0) as a BFS queue.
  • string.ascii_lowercase is "abcdefghijklmnopqrstuvwxyz", handy for the 26-letter version.

Follow-up questions

What an interviewer might ask next, and what changes.

  • Word Ladder II LC 126 — return every shortest ladder, not its length. Run BFS level by level, record all parents of each word on the level it is first reached, then rebuild the paths backwards from endWord.
  • Bidirectional BFS — grow one frontier from beginWord and one from endWord, always expanding the smaller, and stop when they touch. With b neighbours per word and distance d you explore about 2·b^(d/2) words instead of b^d.
  • Minimum Genetic Mutation LC 433 — the same BFS on 8-letter genes over the alphabet A, C, G, T, counting mutations instead of words.
  • Open the Lock LC 752 — BFS over the 10,000 lock combinations: each has 8 neighbours (one wheel up or down) and dead ends act as walls.
  • Network Delay Time LC 743 — what if each letter change had its own cost? Edges are no longer equal, so BFS order is no longer shortest-first; Dijkstra with a heap takes over.
