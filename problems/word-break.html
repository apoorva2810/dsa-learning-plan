Word Break Medium

LeetCode #139 ↗
Status

Decide whether a string can be cut into pieces that are all dictionary words.

Problem

Given a string s and a list of words wordDict, return True if s can be split into a sequence of one or more dictionary words, and False otherwise.

  • The same word may be used any number of times.
  • Every character of s must belong to exactly one word of the split.

Examples

Example 1
Input: s = "leetcode", wordDict = ["leet", "code"]
Output: true
"leet" + "code".
Example 2
Input: s = "applepenapple", wordDict = ["apple", "pen"]
Output: true
"apple" + "pen" + "apple": words can repeat.
Example 3
Input: s = "catsandog", wordDict = ["cats", "dog", "sand", "and", "cat"]
Output: false
"cats" + "and" and "cat" + "sand" both reach "og", which no word covers.

Constraints

  • 1 <= len(s) <= 300
  • 1 <= len(wordDict) <= 1000
  • 1 <= len(wordDict[i]) <= 20
  • lowercase English letters; the words are distinct

Think first try before reading the solution

Taking the first (or longest) word that matches is not safe: try s = "cars" with ["car", "ca", "rs"].
Ask about the last word of a split of the prefix s[:i]: it is some s[j:i]. The split works if that piece is a word and the prefix s[:j] can itself be split.
Let dp[i] say whether s[:i] can be split, with dp[0] = True for the empty prefix. Fill it left to right; the answer is dp[len(s)].

Key idea

Greedy matching fails because an early choice can strand the rest: in "cars", taking "car" leaves "s", while "ca" + "rs" works. We need to know, for every position, whether the text before it can be split at all.

Let dp[i] mean "the prefix s[:i] can be split into words". The last word of such a split is some s[j:i], so

dp[i] = True if there is a j < i with dp[j] True and s[j:i] in the dictionary.

The empty prefix needs no words, so dp[0] = True; the answer is dp[n]. Every cell reads only cells to its left, so a left-to-right pass works. Two speed-ups keep it cheap: put the words in a set (O(1) average lookup), and only try cut points j within the longest word length of i, since a longer piece cannot be a word.

Approaches from the obvious one to the one you want in an interview

breakable(i) answers "can s[:i] be split?". Try every cut point j: if s[j:i] is a word and breakable(j) is True, so is breakable(i). The empty prefix is breakable.

Without memory, the same prefixes are re-examined along every path that reaches them. For "b" + "a" * k with words "a", "aa", "aaa", "aaaa", every way of splitting the a's is tried before the "b" finally fails, which is exponential in k.

Dry run

  1. s = "cars", words {"car", "ca", "rs"}: breakable(4) tries last words ending at 4
  2. "rs" = s[2:4] is a word → is breakable(2) True?
  3. breakable(2): "ca" = s[0:2] is a word and breakable(0) is True → True
  4. so breakable(4) is True

Python

class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> bool:
        words = set(wordDict)                     # O(1) average membership tests

        def breakable(i: int) -> bool:
            """Can the prefix s[:i] be split into dictionary words?"""
            if i == 0:                            # the empty prefix needs no words
                return True
            for j in range(i):                    # the last word would be s[j:i]
                if s[j:i] in words and breakable(j):
                    return True
            return False

        return breakable(len(s))
Time O(2ⁿ)Space O(n)

Every split of the string can be explored; the call stack is at most n deep.

When to use: Only for tiny inputs or to derive the recurrence.

Cache breakable(i). There are only n + 1 prefixes; each tries up to n cut points and hashes a substring of up to n characters, so the total is O(n³) in the worst case (O(n · L²) if you only try pieces up to the longest word length L). Every prefix is decided once, which removes the exponential blow-up.

Dry run

  1. s = "catsandog": breakable(9) finds no word ending at 9 that is preceded by a breakable prefix
  2. each breakable(i) it needed on the way is computed once and cached

Python

class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> bool:
        words = set(wordDict)

        @cache                                    # each prefix length is decided once
        def breakable(i: int) -> bool:
            if i == 0:
                return True
            return any(s[j:i] in words and breakable(j) for j in range(i))

        return breakable(len(s))
Time O(n³)Space O(n)

n + 1 states × up to n cut points × O(n) substring hashing; cache and call stack are O(n).

When to use: A fast way to a correct solution; it only explores prefixes that end at a dictionary word.

Watch it run

Fill dp[0..n] left to right. dp[0] = True. For each i, look for a cut point j with dp[j] True and s[j:i] in the word set; the first one found makes dp[i] True.

Two cheap improvements: test dp[j] before slicing (a False dp[j] makes the substring irrelevant), and only try j >= i - longest, because a piece longer than the longest word cannot be a word. That makes the work O(n · L²) for longest word length L (here L <= 20), instead of O(n³).

Dry run

  1. s = "leetcode", longest word 4: dp[0] = True
  2. dp[1..3]: only dp[0] is True, and "l", "le", "lee" are not words → False
  3. dp[4]: dp[0] True and "leet" is a word → True
  4. dp[5..7]: from dp[4], "c", "co", "cod" are not words → False
  5. dp[8]: dp[4] True and "code" is a word → True

Python

class Solution:
    def wordBreak(self, s: str, wordDict: List[str]) -> bool:
        words = set(wordDict)
        longest = max(len(w) for w in words)
        n = len(s)
        dp = [False] * (n + 1)                    # dp[i] = can s[:i] be split into words?
        dp[0] = True                              # the empty prefix
        for i in range(1, n + 1):
            for j in range(max(0, i - longest), i):   # the last word is s[j:i]
                if dp[j] and s[j:i] in words:     # cheap check first, then the substring
                    dp[i] = True
                    break
        return dp[n]
Time O(n · L²)Space O(n + total dictionary size)

n cells × at most L cut points × O(L) to hash a piece; the word set dominates memory.

When to use: The standard answer; no recursion and an easy bound on the work.

Common mistakes

  • Greedy matching (first or longest word that fits): "cars" with ["car", "ca", "rs"] fails after "car", although a split exists.
  • Checking membership in the list wordDict instead of a set: every check scans up to 1000 words.
  • Forgetting dp[0] = True. Without the empty-prefix base case nothing can ever become True.
  • Off-by-one in slicing: s[j:i] covers indices j .. i-1, so it is the word that ends just before i.
  • Plain recursion without a cache: inputs like "b" + "a" * 30 with ["a", "aa", "aaa"] re-examine the same prefixes exponentially often.

Python notes

  • words = set(wordDict) turns each membership test into an average O(1) hash lookup (plus O(L) to hash the piece).
  • s[j:i] builds a new string of length i - j; s.startswith(w, j) compares in place when you loop over words instead of cut points.
  • @cache on breakable(i) gives the top-down version. It recurses at most len(s) = 300 frames deep, below Python's default recursion limit of 1000, but the same code on a 10^4-character string would need the loop version.
  • any(dp[j] and s[j:i] in words for j in ...) is a compact form of the inner loop; it stops at the first success.
