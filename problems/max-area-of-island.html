Max Area of Island Medium

LeetCode #695 ↗
Status

Find how many cells the largest island in a 0/1 grid covers.

Problem

You are given an m × n grid of integers, where 1 is land and 0 is water. An island is a group of land cells joined horizontally or vertically (corner contact does not count). The area of an island is the number of cells in it.

Return the largest area of any island, or 0 if the grid has no land at all.

Examples

Example 1
Input: grid = [[1,1,0,0],[1,0,0,1],[0,1,1,1],[0,0,0,1]]
Output: 5
The island (1,3), (2,1), (2,2), (2,3), (3,3) has 5 cells; the top-left island has only 3.
Example 2
Input: grid = [[0,0,0,0,0,0,0,0]]
Output: 0
There is no land, so no island.
Example 3
Input: grid = [[1,0],[0,1]]
Output: 1
The two cells touch only at a corner: two islands of area 1.

Constraints

  • 1 <= m, n <= 50
  • grid[i][j] is 0 or 1

Think first try before reading the solution

You already know how to find and mark one island (Number of Islands). What extra number should each flood fill report?
Let the DFS return how many cells it marked. The area found from a cell is 1 (itself) plus whatever its four neighbour calls return.

Key idea

This is Number of Islands with one change: instead of counting islands, measure each one. A flood fill already visits every cell of an island exactly once, so it can count the cells as it goes.

The recursive form reads like a definition: area(r, c) = 1 + area(down) + area(up) + area(right) + area(left), where water, cells off the grid and cells already visited contribute 0. The visited set does two jobs: it stops the recursion from walking in circles, and it makes sure each island is measured once instead of once per cell.

Approaches from the obvious one to the one you want in an interview

For every land cell, measure the island it belongs to from scratch: run a search with its own seen set and return how many cells it found. The answer is the largest of those sizes.

It is correct, but wasteful. An island with k cells is measured k times (once from each of its cells), and each measurement touches all k cells, so a big island costs k² work. On a 50 × 50 grid that is all land, that is about 6 million cell visits instead of 2,500.

Dry run

  1. Example 1: from (0,0) measure {(0,0), (0,1), (1,0)} → 3. From (0,1): the same island again → 3. From (1,0): again → 3.
  2. From (1,3): measure the 5-cell island → 5. Then (2,1), (2,2), (2,3), (3,3) each re-measure it → 5.
  3. Eight measurements for two islands; the answer is max = 5.

Python

class Solution:
    def maxAreaOfIsland(self, grid: List[List[int]]) -> int:
        rows, cols = len(grid), len(grid[0])

        def island_size(sr: int, sc: int) -> int:
            seen = {(sr, sc)}                  # a fresh set every time: nothing is shared between starts
            stack = [(sr, sc)]
            while stack:
                r, c = stack.pop()
                for nr, nc in ((r + 1, c), (r - 1, c), (r, c + 1), (r, c - 1)):
                    if 0 <= nr < rows and 0 <= nc < cols and grid[nr][nc] == 1 and (nr, nc) not in seen:
                        seen.add((nr, nc))
                        stack.append((nr, nc))
            return len(seen)

        best = 0
        for r in range(rows):
            for c in range(cols):
                if grid[r][c] == 1:
                    best = max(best, island_size(r, c))   # the same island is measured again from each of its cells
        return best
Time O((m · n)²)Space O(m · n)

Up to m · n starts, each of which may walk the whole grid.

When to use: Only as the starting point that shows why the visited set must be shared across the whole scan.

Share one visited set across the whole scan, and let the DFS return a number. area(r, c) returns 0 for a cell off the grid, for water, or for a cell already visited. Otherwise it marks the cell and returns 1 + area(down) + area(up) + area(right) + area(left).

Because the cell is marked before the four calls, no cell is ever counted twice, and when the first call returns, its value is exactly the island's size. The scan calls area only on unvisited land, so each island is measured once.

Dry run

  1. Example 1: scan (0,0) → area(0,0) marks it and asks its neighbours.
  2. area(1,0) (down) has no unvisited land around it → returns 1. Up is off the grid → 0. area(0,1) (right) → 1. Left → 0.
  3. area(0,0) = 1 + 1 + 0 + 1 + 0 = 3 → best = 3.
  4. Scan reaches (1,3) → area(1,3) walks (2,3), (3,3), (2,2), (2,1) and returns 5 → best = 5.
  5. No unvisited land is left → return 5.

Python

class Solution:
    def maxAreaOfIsland(self, grid: List[List[int]]) -> int:
        rows, cols = len(grid), len(grid[0])
        visited = set()

        def area(r: int, c: int) -> int:
            if r < 0 or r >= rows or c < 0 or c >= cols:   # off the grid adds nothing
                return 0
            if grid[r][c] != 1 or (r, c) in visited:        # water, or already counted, adds nothing
                return 0
            visited.add((r, c))                             # mark first, so no neighbour counts it again
            return (1                                       # this cell
                    + area(r + 1, c) + area(r - 1, c)       # + everything reachable down and up
                    + area(r, c + 1) + area(r, c - 1))      # + everything reachable right and left

        best = 0
        for r in range(rows):
            for c in range(cols):
                if grid[r][c] == 1 and (r, c) not in visited:
                    best = max(best, area(r, c))            # one call measures one whole island
        return best
Time O(m · n)Space O(m · n)

Each cell is marked once and makes at most four calls. visited and the call stack can each hold every cell in the worst case.

When to use: The standard answer. It is the Number of Islands DFS with a return value.

Watch it run

The same traversal without recursion. Push the first cell of an island and mark it. Repeatedly pop the newest cell, add one to size, and push every unvisited land neighbour, marking each as it is pushed. When the stack is empty, size is the island's area.

The order in which cells are visited differs a little from the recursive version, which does not matter for counting. What you gain is that a huge island can never overflow Python's call stack.

Python

class Solution:
    def maxAreaOfIsland(self, grid: List[List[int]]) -> int:
        rows, cols = len(grid), len(grid[0])
        visited = set()
        best = 0
        for r in range(rows):
            for c in range(cols):
                if grid[r][c] != 1 or (r, c) in visited:
                    continue
                visited.add((r, c))
                stack = [(r, c)]
                size = 0
                while stack:
                    cr, cc = stack.pop()                    # newest cell first (last in, first out)
                    size += 1                               # count a cell when it comes off the stack
                    for nr, nc in ((cr + 1, cc), (cr - 1, cc), (cr, cc + 1), (cr, cc - 1)):
                        if (0 <= nr < rows and 0 <= nc < cols
                                and grid[nr][nc] == 1 and (nr, nc) not in visited):
                            visited.add((nr, nc))           # mark on push: no cell is pushed twice
                            stack.append((nr, nc))
                best = max(best, size)
        return best
Time O(m · n)Space O(m · n)

When to use: When islands can be large enough to hit the recursion limit, or when the interviewer asks for an iterative version.

Common mistakes

  • Marking a cell after recursing into its neighbours: two land neighbours then call each other forever (RecursionError). Add the cell to visited before the four calls.
  • Combining the neighbour results with max instead of +: the area is every cell of the island, not its longest arm.
  • Starting a fresh visited set from every land cell (the brute force below): the answer is right, but an island of k cells is measured k times.
  • Starting best at -1 or at the first island's size: a grid with no land must return 0.
  • Comparing with the string "1": here the cells are integers, unlike Number of Islands.

Python notes

  • Start best = 0; then best = max(best, area(r, c)) handles a grid with no land for free.
  • A recursive function can mark cells and return a value: return 1 + area(...) + ... reads like the definition.
  • The explicit-stack version uses a plain list: append pushes and pop() takes the newest cell, both O(1).
  • To save the visited set you can overwrite visited land with 0 ("sinking" the island), if mutating the input is allowed.

Follow-up questions

What an interviewer might ask next, and what changes.

  • Number of Islands LC 200 — count the islands instead of measuring them: the DFS returns nothing and the scan counts starts.
  • Making A Large Island LC 827 — you may turn one 0 into a 1: label every island with an id and record its area, then for each water cell add 1 to the areas of the distinct islands around it.
  • Island Perimeter LC 463 — measure the coastline instead of the area: every land cell adds 4 minus the number of land neighbours; no traversal is needed.
  • Count Sub Islands LC 1905 — flood each island of the second grid and also check that every one of its cells is land in the first grid.
  • What if diagonal neighbours also connect? — add the four diagonal offsets to the direction list; nothing else changes.
  • Return the cells of the largest island — have the flood fill collect its cells in a list and keep the longest list instead of a number.
