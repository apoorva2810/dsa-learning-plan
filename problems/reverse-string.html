Reverse String Easy 250

LeetCode #344 ↗
Status

Reverse a list of characters in place, swapping mirror pairs from both ends, with O(1) extra memory.

Problem

You are given a list of characters s (each element is a string of length 1).

Reverse it in place: when your function returns, s must hold the same characters in the opposite order. The function returns nothing; the caller looks at the list it passed in.

Do it with O(1) extra memory. You may not build a second list of n characters and copy it back.

Examples

Example 1
Input: s = ["h","e","l","l","o"]
Output: ["o","l","l","e","h"]
h and o trade places, e and the second l trade places, the middle l stays.
Example 2
Input: s = ["H","a","n","n","a","h"]
Output: ["h","a","n","n","a","H"]
Three mirror pairs swap: (H, h), (a, a) and (n, n). Only the first swap changes anything visible.
Example 3
Input: s = ["a"]
Output: ["a"]
A single character is its own reverse. There is no pair to swap.

Constraints

  • 1 <= len(s) <= 10^5
  • s[i] is a printable ASCII character

Think first try before reading the solution

Reversing means the first character ends up last, the second ends up second-to-last, and so on. Which pairs of positions trade places?
Position i swaps with position n - 1 - i. Once you have swapped the first half with the second half, the whole list is reversed; swapping every position would undo the work.
Put left at index 0 and right at index n - 1. Swap s[left] and s[right], step both inward, and stop when they meet or cross.

Key idea

Reversal is a set of swaps between mirror positions: index 0 with index n−1, index 1 with index n−2, and so on until the two indices meet in the middle. Each pair trades places exactly once, and a middle character (when n is odd) mirrors itself and stays put.

Two pointers walk those pairs for you. left starts at the front, right at the back; swap what they point at, then move both inward. The loop runs n // 2 times, visits every position once, and needs only the two integers, so the extra memory is constant. Python's tuple assignment s[left], s[right] = s[right], s[left] does the swap without a temporary variable.

Approaches from the obvious one to the one you want in an interview

Walk the original from the back, appending each character to a new list, then copy that list back into s position by position (so the caller's list changes).

It runs in O(n) time, which is as fast as any reversal can be. The problem is the second list: it holds all n characters, so the extra memory is O(n), and the statement asks for O(1). The copy exists only because we read the back while writing the front; the two-pointer version avoids that by swapping.

Dry run

  1. s = ["h","e","l","l","o"]: copy ← o, then l, l, e, h
  2. copy = ["o","l","l","e","h"]
  3. write back: s[0] = "o", s[1] = "l", ..., s[4] = "h"

Python

class Solution:
    def reverseString(self, s: List[str]) -> None:
        reversed_copy = []
        for i in range(len(s) - 1, -1, -1):      # walk the original from the back
            reversed_copy.append(s[i])
        for i in range(len(s)):                  # write the copy back into the SAME list object
            s[i] = reversed_copy[i]
Time O(n)Space O(n)

Two passes over n characters; the copy holds n characters.

When to use: Fine when memory does not matter; it breaks the O(1) extra-space rule.

Watch it run

Reversal is nothing more than swapping index 0 with index n−1, index 1 with index n−2, and so on until the indices meet. So:

  1. left = 0, right = len(s) - 1.
  2. While left < right: swap s[left] and s[right], then left += 1, right -= 1.

Each mirror pair is swapped exactly once, the middle character of an odd-length list is never touched, and the loop ends after n // 2 rounds. Only two integers are stored.

Dry run

  1. s = ["h","e","l","l","o"]: L=0 h, R=4 o → swap → ["o","e","l","l","h"]
  2. L=1 e, R=3 l → swap → ["o","l","l","e","h"]
  3. L=2, R=2: pointers meet, the middle l stays → done

Python

class Solution:
    def reverseString(self, s: List[str]) -> None:
        left, right = 0, len(s) - 1
        while left < right:
            s[left], s[right] = s[right], s[left]   # swap the mirror pair in one tuple assignment
            left += 1                               # both pointers step inward
            right -= 1
Time O(n)Space O(1)

n // 2 swaps, each O(1); only the two indices are stored.

When to use: The intended answer: linear time, constant extra memory, three lines of logic.

Watch it run

The same swaps written recursively: a helper swaps s[left] with s[right] and calls itself on `(left + 1, right - 1)`, stopping when the pointers meet or cross.

It does the same O(n) work, but every pending call sits on the call stack (the memory Python uses to remember where each unfinished function must resume). The stack grows to about n / 2 frames, so the extra memory is O(n), not O(1), and Python's default recursion limit of 1,000 makes it crash on long inputs. It is worth knowing because interviewers sometimes ask for it, and because it shows that "no extra list" is not the same as "O(1) memory".

Python

class Solution:
    def reverseString(self, s: List[str]) -> None:
        def swap_pair(left: int, right: int) -> None:
            if left >= right:                      # pointers met or crossed: nothing left to swap
                return
            s[left], s[right] = s[right], s[left]  # swap the outer pair ...
            swap_pair(left + 1, right - 1)         # ... then reverse the inner part

        swap_pair(0, len(s) - 1)
Time O(n)Space O(n)

n // 2 + 1 calls; each one keeps a frame on the call stack until the innermost returns.

When to use: Only to show you understand recursion; the iterative loop is strictly better here.

Common mistakes

  • Writing s = s[::-1]. That rebinds the local name s to a new list; the caller's list is untouched and the test sees no change. Mutate the list you were given: swap elements, or use s[:] = s[::-1] / s.reverse().
  • Looping for i in range(n) and swapping s[i] with s[n - 1 - i]. Every pair is swapped twice, so the list ends up exactly as it started. Stop at the middle: range(n // 2), or while left < right.
  • Swapping with two plain assignments, s[left] = s[right] then s[right] = s[left]. The first line overwrites the value the second line needs, so one character is duplicated. Use tuple assignment or a temporary variable.
  • Returning the reversed list instead of changing s. The official signature returns None; LeetCode (and this site's tests) inspect the argument after the call, not the return value.
  • Solving it recursively on the real input size: n = 10^5 means about 50,000 nested calls, far past Python's default recursion limit of 1,000.

Python notes

  • s.reverse() reverses a list in place in C: O(n) time, O(1) extra space, and the shortest correct answer. Interviewers want to see the swap loop at least once, so know both.
  • s[::-1] builds a new reversed list and reversed(s) returns an iterator; neither changes s. Slice assignment s[:] = s[::-1] does change the original object (at the cost of a temporary copy).
  • s[left], s[right] = s[right], s[left] builds the right-hand tuple first, then assigns, so no temporary variable is needed.
  • Strings are immutable in Python, which is why this problem hands you a list of characters. Convert with list(text) and back with "".join(chars) when you need to.

Follow-up questions

What an interviewer might ask next, and what changes.

  • Reverse Words in a String LC 151 — the units are words, not characters, and extra spaces must go: reverse the whole string, then reverse each word back, or split on whitespace, reverse the list and join.
  • Reverse Words in a String III LC 557 — keep the word order but reverse the letters inside each word: run this exact swap loop once per word, with left and right on the word's first and last letter.
  • Reverse String II LC 541 — reverse only the first k characters of every block of 2k: the same swap loop on each window [i, min(i + k, n) - 1] for i stepping by 2k.
  • Reverse Vowels of a String LC 345 — only vowels trade places: each pointer skips past consonants before the swap, like the skipping in Valid Palindrome.
  • Reverse Linked List LC 206 — a linked list has no index you can jump to from the back, so you cannot park a pointer at the end; instead walk once from the head and re-point each next link backwards.
  • Rotate Array LC 189 — rotating by k is three reversals: reverse the whole array, then reverse the first k elements, then the rest.
