Longest Substring Without Repeating Characters Medium

LeetCode #3 ↗
Status

Find the length of the longest stretch of a string in which no character appears twice.

Problem

Given a string s, return the length of the longest substring that contains no repeated character.

A substring is a contiguous run of characters: in "pwwkew", "wke" is a substring, but "pwke" is not (its letters are not next to each other in s).

Examples

Example 1
Input: s = "abcabcbb"
Output: 3
"abc" is the longest stretch without a repeat.
Example 2
Input: s = "bbbbb"
Output: 1
Every substring longer than "b" repeats a "b".
Example 3
Input: s = "pwwkew"
Output: 3
"wke". "pwke" is longer but it is not contiguous.
Example 4
Input: s = ""
Output: 0

Constraints

  • 0 <= len(s) <= 5 * 10^4
  • s consists of English letters, digits, symbols and spaces

Think first try before reading the solution

Checking every substring is slow. Suppose s[left..right] has no repeats and the next character is new to it. What is the longest repeat-free substring ending at right + 1?
If the next character is already inside, the window has to lose characters from the left until that earlier copy is gone. Nothing to the left of the copy can be part of a valid window ending here.
Keep a set of the window's characters. For each right: while s[right] is in the set, remove s[left] and do left += 1; then add s[right] and update the best length right - left + 1.

Key idea

A sliding window is a range s[left..right] that you move along the string instead of rebuilding for every start. Here the window always holds a substring with no repeated character, and a set records which characters are inside it.

Each step extends the window by one character on the right. If that character is already in the window, the window is broken, so left moves forward (removing characters from the set) until the old copy has left. The window is valid again, and its length is a candidate answer.

Both pointers only move forward, so every character enters the window once and leaves at most once. That is O(n) in total, even though there is a loop inside the loop.

Approaches from the obvious one to the one you want in an interview

For each start index, extend the substring one character at a time, keeping a set of what it contains, and stop at the first repeat (any longer substring from that start contains the same repeat). The longest of these runs is the answer.

It is slow because consecutive starts redo almost the same work: starting at i + 1 rescans most of what starting at i already proved repeat-free. With n starts and runs of up to n characters, that is O(n²) for a big alphabet.

Dry run

  1. s = "abcabcbb"
  2. start 0: a, b, c, then a repeats → length 3
  3. start 1: b, c, a, then b repeats → length 3
  4. every start does this again; the best is 3

Python

class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        best = 0
        for start in range(len(s)):
            seen = set()
            for end in range(start, len(s)):
                if s[end] in seen:
                    break                          # longer substrings from `start` repeat too
                seen.add(s[end])
            best = max(best, len(seen))            # length of the repeat-free run from `start`
        return best
Time O(n · min(n, m))Space O(min(n, m))

m is the number of distinct characters possible. Each run stops after at most m + 1 characters, so with a small alphabet it is fast; with a large one it is O(n²).

When to use: Only to see the waste that the sliding window removes.

Keep a window s[left..right] with no repeated characters and a set of its characters.

  1. Move right forward one character, c.
  2. While c is already in the set, remove s[left] from the set and move left forward.
  3. Add c; the window is valid again, so right - left + 1 is a candidate answer.

The shrinking stops exactly when the old copy of c has left, which is the smallest change that makes the window valid. Nothing is ever recomputed: left and right each cross the string once.

Dry run

  1. s = "abcabcbb"
  2. add a, b, c → window abc, best 3
  3. a repeats → remove a → window bca
  4. b repeats → remove b → cab; c repeats → remove c → abc
  5. b repeats → remove a, b → cb; b repeats → remove c, b → b
  6. best stays 3

Python

class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        window = set()                             # characters in s[left..right]
        left = 0
        best = 0
        for right, c in enumerate(s):
            while c in window:                     # repeat: shrink until the old copy of c is gone
                window.remove(s[left])
                left += 1
            window.add(c)
            best = max(best, right - left + 1)
        return best
Time O(n)Space O(min(n, m))

Each character is added once and removed at most once; the set holds at most m distinct characters.

When to use: The standard answer, and the template for every 'longest window with no more than ...' problem.

Watch it run

Instead of removing characters one by one, remember where each character was last seen. When c repeats inside the window, jump left directly to last_seen[c] + 1, just past the old copy.

The jump must only go forward: if the old copy is already left of the window (last_seen[c] < left), it is not a repeat any more. Same O(n), fewer steps when the repeat is far back, and no removals.

Dry run

  1. s = "abba"
  2. a → {a: 0}; b → {b: 1}; window ab
  3. b again at 2: last seen at 1 ≥ left 0 → left = 2, window b
  4. a again at 3: last seen at 0 < left 2 → outside the window, no jump; window ba, length 2

Python

class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        last_seen = {}                             # character -> index of its latest occurrence
        left = 0
        best = 0
        for right, c in enumerate(s):
            if c in last_seen and last_seen[c] >= left:
                left = last_seen[c] + 1            # jump just past the previous copy
            last_seen[c] = right
            best = max(best, right - left + 1)
        return best
Time O(n)Space O(min(n, m))

One pass with O(1) dictionary work per character.

When to use: A slightly faster version of the same idea; watch the last_seen[c] >= left check.

Common mistakes

  • Restarting from an empty window at a repeat. In "dvdf" the answer "vdf" starts right after the first d, so the characters between the two copies must be kept.
  • In the index-map version, moving left backwards. An old index of c may lie before the current window ("abba"): only jump when last_seen[c] >= left, or write left = max(left, last_seen[c] + 1).
  • Recording the length before the window is repaired, which counts a window that still holds the repeat.
  • Forgetting the empty string: the answer is 0, and the code must not read s[0].

Python notes

  • for right, c in enumerate(s) gives the right edge of the window and its character together.
  • set.remove(x) raises KeyError when x is missing (discard does not). Here the removed character is always in the window, so remove doubles as a sanity check.
  • A dict last_seen mapping character → latest index lets left jump in one step instead of crawling one character at a time.

What an interviewer might ask next, and what changes.

  • Longest Substring with At Most Two Distinct Characters LC 159 — repeats are allowed but only two different characters: replace the set with a counter and shrink while it has more than two keys.
  • Longest Substring with At Most K Distinct Characters LC 340 — the same window with any limit k.
  • Longest Repeating Character Replacement LC 424 — the window is valid when at most k characters differ from its most common letter: keep counts instead of a set.
  • Minimum Window Substring LC 76 — find the shortest window that is valid instead: shrink while it stays valid and record the answer inside that loop.
  • Fruit Into Baskets LC 904 — the 'at most two distinct values' window, told as a story about an integer array.
  • Return the substring itself — remember left whenever best improves and return s[best_left:best_left + best].
