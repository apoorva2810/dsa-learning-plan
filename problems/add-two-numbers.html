Add Two Numbers Medium

LeetCode #2 ↗
Status

Add two numbers whose digits are stored in linked lists, ones digit first.

Problem

You are given two non-empty linked lists l1 and l2. Each represents a non-negative integer, one decimal digit per node, stored in reverse order: the head holds the ones digit, the next node the tens digit, and so on.

Return their sum as a linked list in the same format. Neither number has leading zeros, except the number 0 itself (a single node [0]).

Examples

Example 1
Input: l1 = [2, 4, 3], l2 = [5, 6, 4]
Output: [7, 0, 8]
342 + 465 = 807.
Example 2
Input: l1 = [0], l2 = [0]
Output: [0]
Example 3
Input: l1 = [9, 9, 9, 9, 9, 9, 9], l2 = [9, 9, 9, 9]
Output: [8, 9, 9, 9, 0, 0, 0, 1]
9999999 + 9999 = 10009998. The final carry creates a new last node.

Constraints

  • 1 <= number of nodes in each list <= 100
  • 0 <= Node.val <= 9
  • no leading zeros, except the number 0 itself

Think first try before reading the solution

This is the addition you did on paper. Which column do you add first, and which digit sits at the head of each list?
Walk both lists together: column sum = digit + digit + carry. The new digit is total % 10, the new carry is total // 10.
Keep going while either list has nodes or the carry is not zero, treating a finished list as digit 0. Build the answer behind a dummy node.

Key idea

Column addition starts at the ones digit and moves left, carrying 1 whenever a column reaches 10. The reverse order of the lists is a gift: the head of each list is the ones digit, so one forward walk over both lists visits the columns in exactly the order you need.

At each column: total = a + b + carry, write total % 10 as a new node, and carry total // 10 (0 or 1) into the next column. Two details make it complete: the lists can have different lengths (treat a missing digit as 0), and a carry can remain after both lists end (5 + 5 = 10 needs a new node for the 1). The loop condition while l1 or l2 or carry covers both.

Approaches from the obvious one to the one you want in an interview

Read each list into a Python integer (digit × 1, × 10, × 100, …), add the two integers, then write the sum back into a list, ones digit first, with repeated divmod(total, 10).

In Python this works because integers can be arbitrarily large, and it is O(n + m). But it sidesteps the question: the lists can hold 100 digits, far beyond a 64-bit integer in Java or C++, and an interviewer wants to see the carry logic done digit by digit.

Python

class Solution:
    def addTwoNumbers(self, l1: Optional[ListNode], l2: Optional[ListNode]) -> Optional[ListNode]:
        def to_int(node):
            value, place = 0, 1
            while node:                      # the head is the ones digit
                value += node.val * place
                place *= 10
                node = node.next
            return value

        total = to_int(l1) + to_int(l2)
        dummy = tail = ListNode()
        while True:                          # write the digits back, ones first
            total, digit = divmod(total, 10)
            tail.next = ListNode(digit)
            tail = tail.next
            if total == 0:
                break
        return dummy.next
Time O(n + m)Space O(n + m)

Linear in the number of digits (Python's big-integer arithmetic on numbers this size is cheap).

When to use: Only in Python, and only after showing the real solution.

Walk both lists at once, like adding on paper from the right:

  1. a and b are the current digits, or 0 when a list has run out.
  2. total = a + b + carry; append a node with total % 10; set carry = total // 10.
  3. Advance whichever lists still have nodes.

Loop while l1 or l2 or carry. The carry part adds the extra final node when the sum is longer than both inputs. Each column costs O(1), and there are max(n, m) + 1 columns at most.

Dry run

  1. l1 = [2, 4, 3] (342), l2 = [5, 6, 4] (465), carry 0
  2. ones: 2 + 5 + 0 = 7 → digit 7, carry 0
  3. tens: 4 + 6 + 0 = 10 → digit 0, carry 1
  4. hundreds: 3 + 4 + 1 = 8 → digit 8, carry 0
  5. both lists done and carry 0 → [7, 0, 8] (807)

Python

class Solution:
    def addTwoNumbers(self, l1: Optional[ListNode], l2: Optional[ListNode]) -> Optional[ListNode]:
        dummy = ListNode()
        tail = dummy
        carry = 0
        while l1 or l2 or carry:
            a = l1.val if l1 else 0          # a finished list counts as 0
            b = l2.val if l2 else 0
            total = a + b + carry
            carry, digit = divmod(total, 10) # e.g. 15 -> carry 1, digit 5
            tail.next = ListNode(digit)
            tail = tail.next
            l1 = l1.next if l1 else None
            l2 = l2.next if l2 else None
        return dummy.next
Time O(max(n, m))Space O(1)

One step per column; besides the output list, only carry and a few pointers.

When to use: The interview answer; the same loop solves Add Strings and Add Binary.

Common mistakes

  • Stopping when the shorter list ends: the rest of the longer list (and any carry into it) is lost.
  • Forgetting the final carry: [5] + [5] must be [0, 1], not [0].
  • total / 10 is a float in Python 3; use total // 10 (or divmod(total, 10)) for the carry.
  • Converting both lists to Python integers works because Python integers have no size limit, but an interviewer will ask for the digit-by-digit version: in most languages a 100-digit number overflows a 64-bit integer.

Python notes

  • carry, digit = divmod(total, 10) gives both parts in one call: divmod(15, 10) is (1, 5).
  • a = l1.val if l1 else 0 is the conditional expression that turns a finished list into digit 0.
  • while l1 or l2 or carry: relies on truthiness: None and 0 are falsy, so the loop ends exactly when nothing is left.

Follow-up questions

What an interviewer might ask next, and what changes.

  • Add Two Numbers II LC 445 — digits stored most significant first: push both lists' digits onto stacks (or reverse the lists), add from the top, and build the answer by prepending each new node.
  • Plus One Linked List LC 369 — add 1 to a number stored most significant first: find the last digit that is not 9, add one to it, and zero everything after it.
  • Add Strings LC 415 — the same carry loop on two strings, walking both from their right ends with indices.
  • Add Binary LC 67 — base 2: % 2 and // 2 instead of 10.
  • Multiply Strings LC 43 — digit-by-digit multiplication: each pair of digits adds into a result array, then carries are pushed left.
