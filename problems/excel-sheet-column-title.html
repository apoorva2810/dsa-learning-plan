Excel Sheet Column Title Easy 250

LeetCode #168 ↗
Status

Turn a column number into its spreadsheet letters: 1 is A, 26 is Z, 27 is AA, 28 is AB.

Problem

Spreadsheet columns are labelled with letters. Columns 1 to 26 are A to Z. Column 27 is AA, 28 is AB, and so on up to AZ (52), then BA (53) ... ZZ (702), then AAA (703), and so on.

You are given a positive integer columnNumber. Return the label of that column as a string of uppercase letters.

Examples

Example 1
Input: columnNumber = 1
Output: "A"
The first column.
Example 2
Input: columnNumber = 28
Output: "AB"
After Z (26) come AA (27) and AB (28).
Example 3
Input: columnNumber = 52
Output: "AZ"
52 is 2 × 26, yet the last letter is Z, not a 'zero' letter: there is no letter for 0. The two-letter titles AA to AZ cover 27 to 52, so 52 is the last of them.

Constraints

  • 1 <= columnNumber <= 2^31 - 1

Think first try before reading the solution

Write out the labels for 25, 26, 27 and 28: Y, Z, AA, AB. Now try plain base 26 on 26 and 27, with A = 0. What goes wrong?
In base 26 the digits would be 0 to 25, but the labels have no letter for 0: A means 1 and Z means 26. It is a numbering system without a zero, so 26 is a single letter, not a two-letter number.
Subtract 1 from n before each divmod(n, 26). The remainder is then 0 to 25 and maps straight onto A to Z, and the quotient is the number of full blocks of 26 that still have to be named by the letters on the left.

Key idea

Letters look like base 26, and almost are. In real base 26 the digits run 0 to 25, and 26 is written as "1, 0" (one block of 26, plus zero). Column titles have no zero letter: A means 1 and Z means 26, so 26 is written with the single letter Z, and the two-letter titles only start at 27. Plain n % 26 fails exactly at the multiples of 26: it says 0, and there is no letter for 0.

The fix is one subtraction. Shift n down by 1, so the range 1 to 26 becomes 0 to 25, which maps onto A to Z with no gap. Then divmod(n - 1, 26) gives the last letter (the remainder) and how many full blocks of 26 remain (the quotient), and the quotient is again a column number in the same 1-based system, so the same step repeats on it. The letters come out last-first, so reverse them at the end.

Each round divides n by 26, so a 31-bit number needs at most 7 rounds: O(log n) time and output.

Approaches from the obvious one to the one you want in an interview

Plain base 26 fails because titles have no zero letter. One way around it: first work out how many letters the title has, then the conversion becomes ordinary.

There are 26 one-letter titles, 26² two-letter titles, 26³ three-letter titles, and so on. Subtract these group sizes from n while n is bigger than the group; what remains is the 1-based rank of the title within its length group. Make it 0-based and write it as a length-digit base-26 number with A = 0, padding with As: that is the title.

It is correct and it explains the structure, but it is twice the work of the one-line fix below.

Dry run

  1. n = 28: 28 > 26, skip the 26 one-letter titles → n = 2, length 2, 676 two-letter titles
  2. 2 <= 676, so the title has 2 letters and is the 2nd of them. 0-based rank: 1
  3. 1 in two base-26 digits: 1 % 26 = 1 → B, 1 // 26 = 0 → A. Title: AB
  4. n = 52: skip 26 → n = 26, length 2. 0-based rank 25: 25 % 26 = 25 → Z, 0 → A. Title: AZ

Python

class Solution:
    def convertToTitle(self, columnNumber: int) -> str:
        n = columnNumber
        length, block = 1, 26                      # block = how many titles have exactly `length` letters
        while n > block:                           # skip every title shorter than the answer
            n -= block
            length += 1
            block *= 26
        n -= 1                                     # 1-based rank within its length group -> 0-based
        letters = []
        for _ in range(length):                    # plain base 26 now, A = 0, exactly `length` digits
            n, remainder = divmod(n, 26)
            letters.append(chr(ord('A') + remainder))
        return ''.join(reversed(letters))
Time O(log n)Space O(log n)

Both loops run once per output letter, and a 31-bit number has at most 7 letters.

When to use: When you want to see why the off-by-one exists: once the shorter titles are removed, base 26 works as usual.

Watch it run

Shift n down by 1 and take divmod(n, 26). The remainder is 0 to 25 and names the last letter (A to Z). The quotient is the number of full blocks of 26 that the letters to the left must describe, and it is again a 1-based column number, so the same step applies to it. Stop when the quotient is 0 and reverse the letters.

The shift is the whole trick: it turns "1 to 26, no zero" into "0 to 25", which is what % produces. It must happen in every round, because every quotient is 1-based again.

Dry run

  1. n = 28: 28 - 1 = 27, divmod(27, 26) = (1, 1) → letter B, n = 1
  2. n = 1: 1 - 1 = 0, divmod(0, 26) = (0, 0) → letter A, n = 0, stop
  3. letters came out as B, A → reversed: AB
  4. n = 52: 51 % 26 = 25 → Z, 51 // 26 = 1; then 0 % 26 = 0 → A: AZ

Python

class Solution:
    def convertToTitle(self, columnNumber: int) -> str:
        letters = []
        n = columnNumber
        while n > 0:
            n -= 1                                 # 1..26 -> 0..25: there is no letter for 0
            n, remainder = divmod(n, 26)           # remainder names this letter, n = blocks of 26 left
            letters.append(chr(ord('A') + remainder))
        return ''.join(reversed(letters))          # the last letter was produced first
Time O(log n)Space O(log n)

One division per output letter; at most 7 letters for a 31-bit number.

When to use: The interview answer. Be ready to say why the - 1 is inside the loop.

Watch it run

The same arithmetic written as a recurrence: the title of n is the title of (n - 1) // 26 followed by the letter for (n - 1) % 26, and the title of 0 is the empty string. The recursion handles the reversal for you, because the letters on the left are produced by the inner call and come back first.

It is the shortest version to write, at the cost of a call per letter (at most 7 here, so that does not matter).

Dry run

  1. title(28) = title(27 // 26) + letter(27 % 26) = title(1) + 'B'
  2. title(1) = title(0 // 26) + letter(0 % 26) = title(0) + 'A' = '' + 'A' = 'A'
  3. so title(28) = 'A' + 'B' = 'AB'

Python

class Solution:
    def convertToTitle(self, columnNumber: int) -> str:
        if columnNumber == 0:                      # no blocks left: nothing more to write
            return ''
        n = columnNumber - 1                       # the same shift as in the loop version
        return self.convertToTitle(n // 26) + chr(ord('A') + n % 26)
Time O(log n)Space O(log n)

One recursive call per letter, so the call stack is as deep as the title is long.

When to use: When you want the shortest code; the loop version is easier to step through in your head.

Common mistakes

  • Plain base 26 without the shift: n % 26 is 0 for 26, 52, 78, ... and there is no letter for 0. 26 must come out as Z, not as B followed by a missing letter.
  • Subtracting 1 only once, before the loop. The shift is needed in every round, because the quotient is again a 1-based column number. With a single shift, 27 gives BA instead of AA.
  • Forgetting to reverse. The loop produces the rightmost letter first; ''.join(letters) without reversing gives BA for 28.
  • Looping on while n >= 0 or testing n == 0 after the shift. Use while n > 0 on the unshifted value: after the last letter the quotient is 0 and the loop must stop.
  • Mixing it up with the inverse problem (title to number), where you multiply: number = number * 26 + (ord(c) - ord('A') + 1). Here you divide.

Python notes

  • divmod(n, 26) returns (n // 26, n % 26) in one call: the blocks that remain and the letter for this position.
  • chr(ord('A') + r) turns 0..25 into 'A'..'Z'; string.ascii_uppercase[r] does the same with a lookup.
  • Build the letters in a list and ''.join(reversed(letters)) at the end; adding to the front of a string in a loop copies the string each time.
  • Python integers do not overflow, so 2^31 - 1 needs no special care; the loop just runs 7 times.

Follow-up questions

What an interviewer might ask next, and what changes.

  • Excel Sheet Column Number LC 171 — the inverse: letters to number. Scan left to right with total = total * 26 + (letter value 1..26); no off-by-one trick is needed.
  • Base 7 LC 504 — a true base conversion with a zero digit: no shift, but you must handle a negative input and the number 0 itself.
  • Convert a Number to Hexadecimal LC 405 — base 16 with a digit alphabet 0-9a-f; negative numbers are written in two's complement, so mask to 32 bits first.
  • A different alphabet size — with k letters instead of 26 only the constant changes: divmod(n - 1, k). With a digit alphabet that does contain a zero, drop the - 1.
  • How many titles have exactly k letters? — 26^k: the k-letter titles are exactly the k-digit numbers of this zero-less system. That is why 1 + 26 + 676 = 703 is the first three-letter title, AAA.
  • Generate the first m titles in order — instead of converting each number, step a 'string odometer': increment the last letter, and roll Z over to A while carrying left; a full roll-over adds a new A in front.
