Decode String Medium 250

LeetCode #394 ↗
Status

Expand a string written in the nested repeat notation k[text].

Problem

A string is encoded with the rule k[text], which means "write text exactly k times". The text inside the brackets may itself contain other k[text] groups, so groups can be nested. Letters outside any group are written as they are.

Given a valid encoded string s, return the decoded string.

You may rely on the input being well formed: the brackets match, every k is a positive whole number (it can have several digits), and digits only ever appear as repeat counts. A number is always followed directly by [, so inputs such as 3a or 2[4] never occur.

Examples

Example 1
Input: s = "3[a]2[bc]"
Output: "aaabcbc"
3[a] is aaa and 2[bc] is bcbc; the two groups are written one after the other.
Example 2
Input: s = "3[a2[c]]"
Output: "accaccacc"
The inner 2[c] becomes cc, so the outer group is acc, repeated three times.
Example 3
Input: s = "2[abc]3[cd]ef"
Output: "abcabccdcdcdef"
Two groups, then the plain letters ef after them.
Example 4
Input: s = "10[a]"
Output: "aaaaaaaaaa"
A repeat count can have several digits: this is ten, not one followed by zero.

Constraints

  • 1 <= len(s) <= 30
  • s consists of lowercase English letters, digits and the brackets `[` and `]`
  • s is a valid encoding; every repeat count is between 1 and 300

Think first try before reading the solution

Read the string from left to right. At a [, the meaning of what you write changes: what do you have to remember so that you can continue the outer text later?
At [, put aside the text built so far and the repeat count that belongs to the group, and start a fresh, empty text for the inside. What should happen at the matching ]?
At ], take the saved text and count back: the new text is saved + inside * count. A count can have several digits, so build it as number * 10 + digit.

Key idea

Think of each [ as opening a fresh page. Everything up to its matching ] is written on that new page. When the ] closes it, the page is repeated k times and glued onto the end of the page that was open before. "The page that was open before" is the one we set aside most recently, so the pages we set aside form a stack.

Walk through the characters with two variables: current, the text of the page we are writing now, and number, the repeat count being read. A letter is appended to current. A digit extends number (number = number * 10 + digit, so 12 is read as 1, then 12). At [ we push (current, number): the text before the group and the count that applies to it. Then we start over with an empty current and number = 0. At ] we pop (previous, count) and set current = previous + current * count. When the string ends, current is the answer.

Nested groups need no extra code: an inner ] finishes its group first, and that decoded text simply becomes part of the outer group's current.

Approaches from the obvious one to the one you want in an interview

A group with no brackets inside it is easy to expand: a number, [, some letters, ]. A regular expression can find all of those at once, (\d+)\[([a-z]*)\], and replace each with its letters repeated. Groups that were nested become innermost after that, so repeat until no [ is left.

It is correct and short. Each round re-reads the whole string, which has been growing, and the number of rounds equals the nesting depth. Work is about depth times the size of the longest intermediate string, and it hides the structure that a stack makes explicit.

Dry run

  1. "3[a2[c]]": the only group without brackets inside is 2[c] → cc → "3[acc]"
  2. "3[acc]" is now innermost → accaccacc
  3. no [ left → return accaccacc

Python

class Solution:
    def decodeString(self, s: str) -> str:
        # an innermost group: a number, "[", letters only, "]". No bracket can hide inside it.
        innermost = re.compile(r"(\d+)\[([a-z]*)\]")
        while "[" in s:
            # expand every innermost group; groups that were nested become innermost next round
            s = innermost.sub(lambda m: int(m.group(1)) * m.group(2), s)
        return s
Time O(d · L)Space O(L)

One full pass per nesting level d, over a string of up to L characters (L = length of the decoded string).

When to use: A neat one-liner idea, but the stack shows the structure and does less re-reading.

Scan once, keeping current (the text of the group being written) and number (the repeat count being read).

  • letter: append it to current;
  • digit: number = number * 10 + digit;
  • [: push (current, number), then reset current = "" and number = 0;
  • ]: pop (previous, count) and set current = previous + current * count.

At the end, current is the decoded string. The stack remembers, for every group that is still open, the text that came before it and how often it repeats. Nested groups close from the inside out, and each decoded group becomes part of the current of the group around it.

Dry run

  1. s = "3[a2[c]]", current = "", number = 0, stack []
  2. 3 → number = 3; [ → push ('', 3), reset
  3. a → current = a; 2 → number = 2; [ → push ('a', 2), reset
  4. c → current = c
  5. ] → pop ('a', 2): current = a + c * 2 = acc
  6. ] → pop ('', 3): current = ` + acc * 3 = accaccacc`

Python

class Solution:
    def decodeString(self, s: str) -> str:
        stack = []                                # (text before the group, repeat count)
        current = ""                              # the text of the group being written now
        number = 0                                # the repeat count being read
        for ch in s:
            if ch.isdigit():
                number = number * 10 + int(ch)    # counts can have several digits
            elif ch == "[":
                stack.append((current, number))   # remember what came before, and how often this group repeats
                current = ""
                number = 0
            elif ch == "]":
                previous, count = stack.pop()
                current = previous + current * count   # repeat the group, glue it after the saved text
            else:
                current += ch                     # an ordinary letter
        return current
Time O(L), L = length of the decoded stringSpace O(L)

The output has to be built, so at least L work. Each ] also copies the text before its group, which is negligible at this input size.

When to use: The standard answer for this problem.

Watch it run

Every group is a smaller instance of the same problem. A helper decode(i) reads from index i until it reaches the ] that closes its group (or the end of the string) and returns the decoded text together with the index where it stopped. On a digit it builds the count; on [ it calls itself for the inside, repeats the returned text count times and goes on; on ] it returns.

The call stack plays the role of the explicit stack: each waiting call remembers its own pieces and its own count. The recursion depth equals the nesting depth, which is small here.

Python

class Solution:
    def decodeString(self, s: str) -> str:
        def decode(i: int):
            """Decode from s[i] up to the ']' that closes this group (or the end). Returns (text, index where it stopped)."""
            pieces = []                           # decoded text of this group
            count = 0
            while i < len(s):
                ch = s[i]
                if ch.isdigit():
                    count = count * 10 + int(ch)
                elif ch == "[":
                    inner, i = decode(i + 1)      # i now points at the matching ']'
                    pieces.append(inner * count)
                    count = 0
                elif ch == "]":
                    return "".join(pieces), i     # this group is finished
                else:
                    pieces.append(ch)
                i += 1
            return "".join(pieces), i
        return decode(0)[0]
Time O(L), L = length of the decoded stringSpace O(L)

Same work as the stack; the call stack is as deep as the nesting.

When to use: When a recursive description feels more natural, or the interviewer asks for a recursive version.

Common mistakes

  • Reading a number as one digit at a time with int(ch). In 10[a] that gives 0, not 10. Build it with number = number * 10 + int(ch).
  • Not resetting number to 0 at [. The count of one group would leak into the next group.
  • Pushing only the count, or only the text, at [. At ] you need both: the text written before the group and the number of repeats.
  • Repeating too much: the count applies to the text inside the brackets only. It is previous + current * count, not (previous + current) * count.
  • Clearing current at ] after using it. The decoded group becomes part of current again, because it may sit inside an outer group.

Python notes

  • ch.isdigit() tells digits from letters. int(ch) turns one digit character into its value.
  • String repetition does the expansion: "ab" * 3 is "ababab".
  • Put tuples on the stack and unpack them when you pop: previous, count = stack.pop().
  • Strings are immutable, so current += ch builds a new string each time. That is fine at this size. For very large outputs, collect pieces in a list and call "".join(pieces) once.
  • re.sub accepts a function as its replacement. The brute-force version below uses that to expand a group.
