Palindromic Substrings Medium

LeetCode #647 ↗
Status

Count how many contiguous pieces of a string are palindromes, counting each position separately.

Problem

Given a string s, return the number of its substrings that are palindromes (read the same forwards and backwards).

Substrings at different positions count separately even if they contain the same letters: in "aaa" the three single "a"s are three different substrings.

Examples

Example 1
Input: s = "abc"
Output: 3
Only the single letters: "a", "b", "c".
Example 2
Input: s = "aaa"
Output: 6
Three "a", two "aa" and one "aaa".
Example 3
Input: s = "abba"
Output: 6
"a", "b", "b", "a", "bb", "abba".

Constraints

  • 1 <= len(s) <= 1000
  • s consists of lowercase English letters

Think first try before reading the solution

There are about n²/2 substrings. Testing each one from scratch costs O(n) more. Where is the repeated work?
s[i..j] is a palindrome exactly when s[i] == s[j] and s[i+1..j-1] is a palindrome. A table of answers for shorter pieces makes each test O(1).
Or count from the middle: every palindrome has a centre (a letter or a gap). Expand from each of the 2n − 1 centres and add 1 for every successful step outward.

Key idea

This is the counting twin of Longest Palindromic Substring, and the same structural fact solves it: a palindrome with its two ends removed is still a palindrome. So

s[i..j] is a palindrome ⇔ s[i] == s[j] and (j - i < 2 or s[i+1..j-1] is a palindrome).

DP table: is_pal[i][j] stores the answer for each piece. Row i reads row i + 1, so fill the rows from the bottom up, and count every True cell. O(n²) time and memory.

Expand around centres: count while growing. From each centre (n letters for odd lengths, n − 1 gaps for even lengths), every step outward that still matches is one more palindrome, and the first mismatch ends that centre for good, because every larger piece around it contains the mismatched pair. That gives the same O(n²) time with O(1) memory.

Approaches from the obvious one to the one you want in an interview

Enumerate every pair (i, j) with i <= j and check whether s[i..j] equals its reverse. Count the hits.

About n²/2 substrings, each checked in O(n), gives O(n³). The work is wasted because checking "racecar" repeats the check of "aceca" that was already done.

Dry run

  1. s = "aba": length 1 → 3 palindromes
  2. "ab", "ba" → no
  3. "aba" → yes; total 4

Python

class Solution:
    def countSubstrings(self, s: str) -> int:
        n = len(s)
        count = 0
        for i in range(n):
            for j in range(i, n):
                piece = s[i:j + 1]
                if piece == piece[::-1]:      # O(length) test
                    count += 1
        return count
Time O(n³)Space O(n)

n(n + 1)/2 substrings, each copied and reversed.

When to use: Only to confirm answers on small strings.

is_pal[i][j] is True when s[i..j] is a palindrome. A cell is True when the end characters match and either the piece is at most 2 long or is_pal[i + 1][j - 1] is True. Every True cell is one palindromic substring, so count them while filling.

The cell (i + 1, j - 1) lies in the next row, so rows are filled from i = n - 1 down to 0 (filling by increasing length works too). O(n²) cells, O(1) each.

Dry run

  1. s = "abba": row 3: "a" True (count 1)
  2. row 2: "b" True, "ba" False (count 2)
  3. row 1: "b", "bb" True, "bba" False (count 4)
  4. row 0: "a" True, "ab", "abb" False, "abba" True since the inside "bb" is True (count 6)

Python

class Solution:
    def countSubstrings(self, s: str) -> int:
        n = len(s)
        is_pal = [[False] * n for _ in range(n)]   # is_pal[i][j]: is s[i..j] a palindrome?
        count = 0
        for i in range(n - 1, -1, -1):             # bottom-up: row i reads row i + 1
            for j in range(i, n):
                if s[i] == s[j] and (j - i < 2 or is_pal[i + 1][j - 1]):
                    is_pal[i][j] = True
                    count += 1
        return count
Time O(n²)Space O(n²)

n(n + 1)/2 cells, constant work each; an n × n table.

When to use: When later steps need to look up arbitrary pieces (e.g. partitioning).

Watch it run

Loop over the 2n − 1 centres. For centre number c, start with left = c // 2 and right = left + c % 2 (a letter when c is even, a gap when it is odd). While left and right are inside the string and the characters match, count one palindrome and step outward.

The first mismatch ends the centre: every wider piece around it would contain that same mismatched pair. Same O(n²) worst case as the table ("aaaa..."), but O(1) memory.

Dry run

  1. s = "aaa": centre letter 0 → "a" (1)
  2. gap 0-1 → "aa" (2); letter 1 → "a", "aaa" (4)
  3. gap 1-2 → "aa" (5); letter 2 → "a" (6)

Python

class Solution:
    def countSubstrings(self, s: str) -> int:
        n = len(s)
        count = 0
        for centre in range(2 * n - 1):        # even numbers = letters, odd numbers = gaps
            left = centre // 2
            right = left + centre % 2
            while left >= 0 and right < n and s[left] == s[right]:
                count += 1                     # s[left..right] is a palindrome
                left -= 1
                right += 1
        return count
Time O(n²)Space O(1)

Each centre expands at most n/2 times; nothing is stored.

When to use: The interview answer: simplest code, constant memory.

Common mistakes

  • Skipping even-length centres: "abba" would count only its 4 letters instead of 6, because "bb" and "abba" are both centred on a gap.
  • Counting distinct strings instead of positions. "aaa" has 6 palindromic substrings, not 3.
  • Filling the table with i increasing: is_pal[i][j] needs is_pal[i+1][j-1] from the row below, which would not exist yet. Go bottom-up (or by length).
  • Continuing to expand after a mismatch. Once s[l] != s[r], every wider piece around that centre contains the same mismatched pair, so stop.

Python notes

  • [[False] * n for _ in range(n)] creates n independent rows; [[False] * n] * n would alias one row n times.
  • range(n - 1, -1, -1) walks the rows from the bottom, which is the order the recurrence needs.
  • A memoised is_pal(i, j) with @cache is another way to fill the table top-down; it recurses about n/2 levels, well under Python's default recursion limit of 1000, but stores up to n²/2 results.
  • Summing booleans works because True == 1: sum(row.count(True) for row in table) counts the True cells.

Follow-up questions

What an interviewer might ask next, and what changes.

  • Longest Palindromic Substring LC 5 — return the longest palindrome instead of counting: the same centres, keeping the widest span.
  • Palindrome Partitioning LC 131 — list every way to cut s into palindromes: backtracking over cut points, with this table for O(1) palindrome checks.
  • Palindrome Partitioning II LC 132 — the fewest cuts so that every piece is a palindrome: a 1-D DP over prefixes on top of is_pal.
  • Longest Palindromic Subsequence LC 516 — letters may be skipped: a 2-D DP over (i, j) where mismatched ends drop one side.
  • Count distinct palindromic substrings — collect the palindromes found by the expansions in a set (fine for small n), or use a palindromic tree (eertree), which stores each distinct palindrome once in O(n).
  • O(n) counting — Manacher's algorithm computes the maximal radius at every centre in O(n); the count is the sum of (radius + 1) // 2 over the centres of the transformed string.
