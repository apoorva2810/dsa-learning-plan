How to use this site

  1. Follow the roadmap. Topics are ordered so each one uses only ideas from earlier ones. Inside a topic, problems go easy → hard.
  2. Try before you read. Every problem has hints you reveal one at a time and a scratchpad. Spend 15–20 minutes on your own first; that is where the learning happens.
  3. Read the approaches in order. Each problem shows the obvious solution first, then the better one, then the one you want in an interview, with the why at every step.
  4. Watch it run. Each approach you can trace has a step-by-step player. Press ▶, or use ← → to step. Change the input and watch again.
  5. Run the Python (optional). The playground runs the real test cases in your browser. Edit a solution, break it, fix it. It needs the site folder served over http (any static file server); everything else works by opening index.html directly.
  6. Mark your status (attempted / solved / needs review) and come back to "needs review" problems a week later.

Keyboard: Ctrl+K or / to search, [ and ] to move between problems, ← → inside a visualiser.
